$$N \ge 500000,\ \delta \le 1,\ M < K,\ 2K < N,\ 1000M \le 735K,\ \delta < L \le N \implies \tbinom{2N+\delta}{N-M} \ne \tbinom{2N+L}{N-K}$$

T. Yamada, Necessary conditions for binomial collisions, arXiv:2002.07043 (2020), Theorem 1.1: a collision C(2N+δ, N−M) = C(2N+L, N−K) with δ ∈ {0,1}, L > δ, 0 ≤ M < K < N/2 and M ≤ 0.735K has L > N(1.3132 log²(2N) − 2.00271). The proof assumes N ≥ 500000, which it takes from Blokhuis–Brouwer–de Weger 2017; at N ≥ 500000 the bound exceeds N, so L ≤ N is excluded.
