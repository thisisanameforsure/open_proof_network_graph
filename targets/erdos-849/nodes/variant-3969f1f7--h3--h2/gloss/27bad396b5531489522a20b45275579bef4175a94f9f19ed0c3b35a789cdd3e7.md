$$\exists a_2\ \forall a \ge a_2$: for a solution $(n,k)$ of $\binom{n}{k} = a$ with $e^{(\log n)^{5/6}} \le k \le n/2$, $\#\{n' > n : \binom{n'}{k'} = a,\ 1 \le k' < k,\ 2k' \le n',\ |n-n'| + |k-k'| \le \exp((\log\log a)^{9/10})\} \le 1$$

MRSTT Proposition 1.10 with ε = 1/20: at most one other left-half solution (n', m') with m' < m, n' > n and |m − m'| + |n − n'| ≪ exp((log log t)^{19/20}); c·exp(x^{19/20}) ≥ exp(x^{9/10}) for x large, whatever the implied constant c, so the hole is implied for a ≥ a₂. Rows n' are at most the solutions.
