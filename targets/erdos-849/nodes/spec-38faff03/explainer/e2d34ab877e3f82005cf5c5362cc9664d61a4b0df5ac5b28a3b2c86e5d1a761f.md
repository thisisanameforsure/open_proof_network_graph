## Overview

Fix $a$ and a row $n$ with $\binom{n}{k} = a$ for some $1 \le k$, $2k \le n$. Then $2 \le 2k \le n$, which is the lower end. For the upper end the proof shows $n \le \binom{n}{k}$, using the helper lemma (`step_lt`, `mono_lt`) that $j \mapsto \binom{n}{j}$ is strictly increasing on $0 \le j \le n/2$: for one step, $\binom{n}{j+1}(j+1) = \binom{n}{j}(n-j)$ with $n - j > j + 1$ when $2(j+1) \le n$, and induction chains the steps.

## The case $k > 1$ {steps: s1}

Strict monotonicity gives $\binom{n}{1} < \binom{n}{k}$, and $\binom{n}{1} = n$, so $n < a$.

## The case $k = 1$ {steps: s2}

Then $k = 1$ and $a = \binom{n}{1} = n$, so $n \le a$ with equality.
