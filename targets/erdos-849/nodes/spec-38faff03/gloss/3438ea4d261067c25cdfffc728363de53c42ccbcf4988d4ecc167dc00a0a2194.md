label: rows holding a lie in [2, a]

$$\forall a \in \mathbb{N}:\quad \bigl\{\, n : \exists k \ge 1,\ 2k \le n,\ \tbinom{n}{k} = a \,\bigr\} \subseteq [2, a]$$

$[2, a]$ is the set of natural numbers $n$ with $2 \le n \le a$ (`Set.Icc 2 a`, empty when $a < 2$).

In words: a row $n$ holding $a$ as $\binom{n}{k}$ with $1 \le k \le n/2$ has $2 \le n \le a$. So the set the root counts is always finite, and its count is never the $0$ that `ncard` gives an infinite set.
