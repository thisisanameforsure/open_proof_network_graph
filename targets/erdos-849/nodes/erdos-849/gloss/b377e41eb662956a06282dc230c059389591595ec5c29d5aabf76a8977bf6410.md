$$\forall t \ge 1\ \ \exists a \in \mathbb{N}:\quad \#\bigl\{\, n \in \mathbb{N} \;:\; \exists k \ge 1,\ 2k \le n,\ \tbinom{n}{k} = a \,\bigr\} = t$$

Here $t$, $a$, $n$, $k$ are natural numbers, and $2k \le n$ is the range $1 \le k \le n/2$ written without division.

Two Lean conventions matter. The set collects **rows** $n$ of Pascal's triangle, not pairs $(n, k)$: a row is counted once however many $k$ give $a$. (In this range a row gives $a$ at most once, so the row count equals the number of solutions $(n, k)$; that is the statement `spec-12191c69`.) And the count is `Set.ncard`, which is $0$ for an infinite set as well as for the empty set; every set here lies in $[2, a]$ (the statement `spec-38faff03`), so it is always finite.

In words: for every $t \ge 1$ there is a number $a$ that appears as $\binom{n}{k}$ with $1 \le k \le n/2$ in exactly $t$ rows $n$.
