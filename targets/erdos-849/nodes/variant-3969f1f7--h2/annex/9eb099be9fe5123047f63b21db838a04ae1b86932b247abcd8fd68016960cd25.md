Numerics for the middle region of the Singmaster skeleton (Erdős 849), exact search, 2026-10-26.

What was computed. Every coincidence C(n,k) = C(m,j) with k > j ≥ 2, 2k ≤ n and 2j ≤ m, in exact 128-bit integer arithmetic (program collide.c, kept in the tester's evidence folder): all coincidences in which some k ≥ 4 occurs, for values up to 10^37 (every C(n,k) ≤ 10^37 with k ≥ 4 was generated, about 3.9 × 10^9 of them for k = 4 alone, and tested against every smaller j by exact root extraction); and the pair (k, j) = (3, 2) for values up to 10^28 (about 3.9 × 10^9 values C(n,3)). Run time 40 minutes on one laptop core.

Result. The only coincidences found are the known ones:

```
120   = C(10,3)  = C(16,2)
210   = C(10,4)  = C(21,2)
1540  = C(22,3)  = C(56,2)
3003  = C(14,6)  = C(15,5) = C(78,2)
7140  = C(36,3)  = C(120,2)
11628 = C(19,5)  = C(153,2)
```

The (3,2) pair is completely solved (Avanesov, Acta Arith. 12 (1966) 409–420: only 120, 1540, 7140), and any value with three or more rows at k ≥ 2 has a row with k ≥ 4. Hence for every a ≤ 10^37 the number of rows n holding a with 2 ≤ k ≤ n/2 is at most 3, and equals 3 only for a = 3003. Together with the row n = a (k = 1), every a ≤ 10^37 lies in at most 4 rows of the half triangle.

Where these fall in the skeleton's regions. With the threshold exp((log n)^{5/6}) (natural log): every coincidence above except the last lies below the threshold in both rows (for n ≤ 221 the threshold exceeds k; for example n = 78 gives about 30.2, n = 15 about 9.9), so all small multiplicity lives in the middle region 2 ≤ k < exp((log n)^{5/6}). The last, Lind's C(104,39) = C(103,40), lies in the interior region in both rows (thresholds about 36.4 and 36.2), and is an instance of the sharpness of Matomäki–Radziwiłł–Shao–Tao–Teräväinen's Theorem 1.3 (two interior solutions, their Remark 1.4).

What this says about the middle hole (∃ K B, every a has at most B rows with K < k < exp((log n)^{5/6})). Up to 10^37 the data are consistent with (K, B) = (1, 3) (only 3003 needs 3: k = 2, 5, 6), (2, 2) (3003: k = 5, 6), and (5, 1). They exclude (1, 2), (2, 1) and (5, 0) for the shapes as stated. The search is evidence, not proof; the wider search of Blokhuis, Brouwer and de Weger (Integers 17 (2017) #A64, Theorem 2.2) finds no new coincidence with C(n,k) ≤ 10^60 or n ≤ 10^6, and de Weger's conjecture (their Conjecture 2.1) is that the list above, with Lind's Fibonacci family, is complete — under which Matomäki et al. (Remark 1.5) get at most one solution in 2 ≤ k ≤ exp((log n)^{2/3+ε}) for large values.
