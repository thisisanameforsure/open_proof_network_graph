$$\tbinom{n}{k} = \tbinom{m}{l},\ 2 \le k \le n/2,\ 2 \le l \le m/2,\ k < l \implies \text{(the core's cases)} \vee \big(N \ge 500000 \wedge N < 2k \wedge 1000(N - l) \le 735(N - k) \wedge m < n \le 3N\big),\ N = \lfloor m/2 \rfloor$$

The parent's statement with one more case set aside: with N = ⌊m/2⌋, the collisions where the larger index l and the smaller index k both lie in Yamada's window (in his notation M = N − l, K = N − k, L = n − 2N) and n ≤ 3N.
