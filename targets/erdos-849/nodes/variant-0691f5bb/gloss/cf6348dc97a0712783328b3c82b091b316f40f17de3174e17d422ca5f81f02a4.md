$$\exists a \in \mathbb{N}:\quad \#\bigl\{\, n \in \mathbb{N} \;:\; \exists k \ge 1,\ 2k \le n,\ \tbinom{n}{k} = a \,\bigr\} = 2$$

Here $a$, $n$, $k$ are natural numbers and $2k \le n$ is the range $1 \le k \le n/2$ without division. The set collects **rows** $n$, each counted once, and its size is `Set.ncard`, which is $0$ for an infinite set as well as an empty one.

In words: some number $a$ appears as $\binom{n}{k}$ with $1 \le k \le n/2$ in exactly two rows of Pascal's triangle. This is the case $t = 2$ of the root `erdos-849`.
