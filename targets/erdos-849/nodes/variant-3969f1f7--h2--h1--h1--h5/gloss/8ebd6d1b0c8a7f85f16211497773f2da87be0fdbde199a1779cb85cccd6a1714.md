$$\binom{n}{2} = \binom{m}{8},\ n \ge 4,\ m \ge 16 \Rightarrow (n,m) = (221,17)$$

R. J. Stroeker and B. M. M. de Weger, Math. Comp. 68 (1999) 1257–1281: C(n,2) = C(m,8) solved completely; the only half-triangle solution is 24310 = C(221,2) = C(17,8). Via BBdW 2017 Thm 2.2.
