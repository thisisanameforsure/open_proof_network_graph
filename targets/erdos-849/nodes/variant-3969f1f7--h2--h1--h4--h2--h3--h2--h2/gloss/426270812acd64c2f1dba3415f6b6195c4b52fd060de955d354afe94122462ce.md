$$\tbinom{n}{k} = \tbinom{m}{l},\ 2 \le k \le n/2,\ 2 \le l \le m/2,\ k < l \implies \text{(the parent's cases)} \vee \big(n > 10^6 \wedge 6m \le 5n \wedge n \le 6k\big)$$

The parent's statement with one more case set aside: $n > 10^6$, $m \le 5n/6$ and $k \ge n/6$. There the interval $(\max(m, n - k), n]$ contains Nagura's prime, which divides $C(n,k)$ and not $C(m,l)$. What remains are collisions with $m > 5n/6$ or $k < n/6$.
