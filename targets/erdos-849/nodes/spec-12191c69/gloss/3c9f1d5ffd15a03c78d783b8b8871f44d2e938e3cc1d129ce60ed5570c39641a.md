$$\forall a \in \mathbb{N}:\quad \#\bigl\{\, n : \exists k \ge 1,\ 2k \le n,\ \tbinom{n}{k} = a \,\bigr\} \;=\; \#\bigl\{\, (n, k) : 1 \le k,\ 2k \le n,\ \tbinom{n}{k} = a \,\bigr\}$$

Both counts are `Set.ncard` (which is $0$ for an infinite set); both sets are in fact finite. The left side is the set the root `erdos-849` counts, rows $n$; the right side counts solutions $(n, k)$, which is what the problem's words count.

In words: for every $a$, the number of rows of the half triangle $1 \le k \le n/2$ holding $a$ equals the number of solutions of $\binom{n}{k} = a$ there, so the root counts what the problem asks about.
