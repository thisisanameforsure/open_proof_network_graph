## Each row gets its $k$ {steps: hf hmaps}

Fix $K$ and $a$, and let $R$ be the set of rows $n$ with $\binom{n}{k} = a$ for some $2 \le k \le K$ with $2k \le n$. For each $n \in R$ choose one such $k$ and call it $f(n)$. Then $2 \le f(n) \le K$, so $f$ maps $R$ into $\{1, \dots, K\}$.

## Different rows get different $k$ {steps: hinj}

Suppose $n \ne m$ are in $R$ with $f(n) = f(m) = k$, say $n < m$. Then $\binom{n}{k} = a = \binom{m}{k}$. But for $k \ge 1$ and $k \le n$, $\binom{\cdot}{k}$ is strictly increasing: $\binom{n+1}{k} = \binom{n}{k} + \binom{n}{k-1}$ with $\binom{n}{k-1} > 0$ (helpers `choose_lt_succ_n`, chained by induction in `choose_strict_n`). So $\binom{n}{k} < \binom{m}{k}$, a contradiction; the case $m < n$ is the same. Hence $f$ is injective on $R$.

## Counting {steps: this}

An injective map from $R$ into the finite set $\{1, \dots, K\}$ gives $|R| \le K$ (`Set.ncard_le_ncard_of_injOn`), which is the statement.
