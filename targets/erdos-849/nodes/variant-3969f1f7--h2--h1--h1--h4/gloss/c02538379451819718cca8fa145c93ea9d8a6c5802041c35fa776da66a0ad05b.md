$$\binom{n}{2} = \binom{m}{6},\ n \ge 4,\ m \ge 12 \Rightarrow (n,m) = (78,14)$$

R. J. Stroeker and B. M. M. de Weger, Elliptic binomial Diophantine equations, Math. Comp. 68 (1999) 1257–1281: C(n,2) = C(m,6) solved completely by elliptic logarithms; the only half-triangle solution is 3003 = C(78,2) = C(14,6). Via BBdW 2017 Thm 2.2.
