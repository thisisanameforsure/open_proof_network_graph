$$\log a \le k \log n,\quad 3 \le k \Rightarrow k \le 2\log a,\quad e^{(\log n)^{5/6}} \le k \Rightarrow (k \ge 3 \wedge \log n \le (\log k)^{6/5})$ for a left-half solution $(n,k)$ of $\binom{n}{k}=a$$

Elementary: k ≤ 2 forces n ≤ 1 under the threshold; 2^k ≤ C(2k,k) ≤ C(n,k) = a gives k ≤ 2 log a; a = C(n,k) ≤ n^k gives log a ≤ k log n; the threshold exp((log n)^(5/6)) ≤ k gives log n ≤ (log k)^(6/5).
