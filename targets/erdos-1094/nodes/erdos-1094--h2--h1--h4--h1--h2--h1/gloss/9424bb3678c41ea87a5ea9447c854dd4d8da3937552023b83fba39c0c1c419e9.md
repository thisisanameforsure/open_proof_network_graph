$$\exists K\ \forall n,k:\ \text{(the node's hypotheses)} \wedge 2 \le \gcd(n,k) < k \Rightarrow k \le K$$

The case gcd(n,k) = k is closed in the assembly. When gcd(n,k) = k, k ∣ n, so n/k = q is prime and k·q = n ∣ k!, giving q ≤ k; with k² ≤ n, q = k, so k is prime and k² ∣ k!, i.e. k ∣ (k-1)!, impossible. Only proper divisors 2 ≤ gcd(n,k) < k remain.
