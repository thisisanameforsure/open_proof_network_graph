$$\exists\, \varepsilon : \mathbb{R},\ 0 < \varepsilon$$

The statement is the $\varepsilon$-form of the prime number theorem for $\theta$: for every $\varepsilon > 0$ there is a threshold beyond which $|\theta(x) - x| \le \varepsilon x$. Its only hypothesis is $0 < \varepsilon$, so the witness exhibits $\varepsilon = 1$ with `one_pos`.
