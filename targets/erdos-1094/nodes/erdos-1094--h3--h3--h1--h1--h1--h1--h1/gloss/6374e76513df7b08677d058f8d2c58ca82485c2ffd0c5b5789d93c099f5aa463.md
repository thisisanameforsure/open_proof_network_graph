$$\Bigl(\forall \psi \in C_c^\infty(0,\infty):\ \tfrac{1}{X}\sum_n f(n)\psi(n/X) \to A\int\psi\Bigr) \Rightarrow \tfrac{1}{N}\sum_{n<N} f(n) \to A$$

Given the smoothed limit for every C² test function supported in (0, ∞), and f ≥ 0, the partial sums have the same mean: dyadic blocks give S(x) = O(x), then bumps sandwich 1_{[ε,1]}.
