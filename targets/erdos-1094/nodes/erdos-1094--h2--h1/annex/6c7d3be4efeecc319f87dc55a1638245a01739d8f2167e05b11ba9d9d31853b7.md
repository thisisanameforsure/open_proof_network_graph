A second route through this range: van Doorn and Tang's 2026 theorem leaves only a thin strip above k², so Konyagin's bound is needed up to k² + 3k^(61/40) rather than up to k³.

**The input.** The same as the annex on erdos-1094--h2--h2. W. van Doorn and Q. Tang, arXiv:2606.19863 (2026), Theorem 1.1, formalised in Lean in github.com/Woett/ChatGPT-s-note-on-Erdos451 from one axiom (Baker–Harman–Pintz). For all large k and 2k < n ≤ exp(log² k / (20 log log k)), some prime p with k < p < k + 3k^(21/40) divides (n − k)⋯(n − 1). The two holes h_bhp and h_vdt are word for word the holes erdos-1094--h2--h2--h1 and erdos-1094--h2--h2--h2 of that skeleton, so they attach to this node as lemmas: one proof serves both branches.

**Why it applies here.** Take an exception with k² ≤ n < k³: the least prime factor of C(n, k) exceeds ⌊n/k⌋. For large k, k³ ≤ exp(log² k / (20 log log k)), since log² k / (20 log log k) ≥ 3 log k once log log k ≤ log k / 60. The assembly proves this from `Real.isLittleO_log_id_atTop`. So n + 1 is in van Doorn and Tang's range. Their prime p divides n(n − 1)⋯(n − k + 1) = k! · C(n, k) and exceeds k, so it divides C(n, k). If moreover n ≥ k(k + 3k^(21/40)), then pk < k(k + 3k^(21/40)) ≤ n, so p ≤ ⌊n/k⌋, and (n, k) is not an exception.

**The decomposition.**

- **h_bhp**, **h_vdt**: as on erdos-1094--h2--h2: Baker–Harman–Pintz, and "BHP fails, or Theorem 1.1 holds", which their Lean file proves.
- **h_strip**: for large k, no exception has k² ≤ n < k(k + 3k^(21/40)). The assembly passes it, as on h2--h2, the proved fact that k⌊n/k⌋ divides k!.

**What this is and is not.** Compared with the existing skeleton of this node (one hole, g(k) > k³, i.e. no good C(n, k) with 2k ≤ n < k³ for large k), h_strip asks much less. It covers only n < k² + 3k^(61/40), and it keeps the full exception hypothesis rather than goodness alone. Every exception in the strip is a good binomial coefficient (⌊n/k⌋ ≥ k), so h_strip follows from g(k) > k² + 3k^(61/40) for large k. Konyagin's g(k) ≫ exp(c log² k) and Granville–Ramaré's earlier bound both give that, so the strip is a known theorem too, by the same analytic methods. The gain is in what a formalisation must reach: just past k², instead of k³. In the strip the window must also avoid every prime in (k, ⌊n/k⌋], which none of the bounds on g(k) uses. Like the cut on h2--h2, this one is asymptotic: it takes effect only for k beyond the point where k³ ≤ exp(log² k / (20 log log k)), and the node asks for exactly such a bound.
