A 2026 theorem removes a large range from the open core, and its proof is already in Lean apart from one published prime-gap theorem.

**The input.** W. van Doorn and Q. Tang, *Consecutive integers free of certain prime factors*, arXiv:2606.19863 (June 2026), Theorem 1.1: for all sufficiently large k and every integer n with 2k < n ≤ exp(log² k / (20 log log k)), the product (n − k)(n − k + 1)⋯(n − 1) is divisible by a prime p with k < p < k + 3k^θ, θ = 21/40. Their repository (github.com/Woett/ChatGPT-s-note-on-Erdos451, file `ErdosProblem451.lean`, Lean 4.28.0, about 4700 lines, produced by Harmonic's Aristotle) proves this as `main_theorem` from a single axiom, `bhp`: Baker, Harman and Pintz's theorem that for large k the interval (k, k + k^θ) holds at least C k^θ / log k primes. Konyagin's theorem on fractional parts (Mathematika 46 (1999), Theorem 2), which the argument uses, is proved in the file as `konyagin_thm`. I have not checked their file against the pinned toolchain; the hole statements below copy their statements with the two definitions (`theta`, and `primeCard`, `Pprod`) unfolded, so that a port is mechanical.

**Why it applies here.** This node asks for a bound on k over the exceptions with n ≥ k³: 0 < k and the least prime factor of C(n, k) exceeds ⌊n/k⌋. Apply Theorem 1.1 at n + 1: the product becomes n(n − 1)⋯(n − k + 1) = k! · C(n, k), and 2k < n + 1 holds since n ≥ k³. The prime p it gives is greater than k, so it does not divide k!, and therefore divides C(n, k). And p < k + 3k^θ ≤ 4k ≤ k² ≤ ⌊n/k⌋ once k ≥ 4. So C(n, k) has a prime factor ≤ ⌊n/k⌋, and (n, k) is not an exception. Hence for all large k there is **no** exception with k³ ≤ n and n + 1 ≤ exp(log² k / (20 log log k)).

**The decomposition.**

- **h_bhp**: Baker–Harman–Pintz, exactly as van Doorn and Tang state it. A published theorem (Proc. LMS 83 (2001)), deep and not formalised.
- **h_vdt**: "BHP fails, or Theorem 1.1 holds". Their file proves exactly this: its `main_theorem` assumes `bhp` and nothing else. Proving the hole means porting that file to the pinned Lean and Mathlib, with every helper lemma turned into a `have` (the gate takes one declaration), or splitting it by a further skeleton along their four cases (n ≤ ½k^(2−θ), up to k²/log² k, up to ½k^(2+θ), and beyond).
- **h_beyond**: the open core that remains. For large k, no exception has n ≥ k³ and n + 1 > exp(log² k / (20 log log k)). The assembly also proves, by the fixed-k argument already proved on erdos-1094--h1, that k⌊n/k⌋ divides k!, and passes that to the hole as a hypothesis. So the hole asks about n in the window (exp(log² k / (20 log log k)) − 1, k! + k) lying within k of a multiple of k that divides k!.

The assembly is proved: it splits on whether n + 1 exceeds the bound, takes the prime from h_vdt (with h_bhp discharging its first disjunct), and shows that prime divides C(n, k) and is at most ⌊n/k⌋.

**What this is and is not.** h_beyond is strictly weaker than this node: it is this node restricted to n beyond an explicit bound, with one more hypothesis. The cut is asymptotic. log² k / (20 log log k) exceeds 3 log k only once log k > 60 log log k, roughly k > e^400, so for every k anyone will compute with, nothing is removed. But the node asks for one bound K on all exceptions, which is exactly an asymptotic statement, and for all large k the cut removes everything from k³ up to exp(c log² k / log log k). h_bhp and h_vdt together are a published theorem. h_beyond is still Ecklund's conjecture in finitely-many form, on a range that now starts at exp(log² k / (20 log log k)) for large k instead of at k³.
