$$\exists\, c \in \mathbb{R},\ 0 < c$$

The only hypothesis before the statement's existential quantifier $\exists K$ is $0 < c$, so the witness exhibits a positive real: $c = 1$ with `one_pos`. It says nothing about whether any $(n, k)$ meets the inner hypotheses.
