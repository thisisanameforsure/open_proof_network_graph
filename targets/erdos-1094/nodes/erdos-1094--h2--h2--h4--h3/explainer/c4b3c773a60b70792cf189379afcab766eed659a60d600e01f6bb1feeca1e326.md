## Overview

Fix $H = k^{3/5}$, $W = k^{1/100}$ and $\delta = H/k$. The claim: for every $\eta > 0$ there are $c > 0$ and $k_0$ such that for $k \ge k_0$, every natural $n$ with $k^3 \le n \le \exp(c\log^2 k)$ and every finite set $S$ of integers $m \in (k, k+H]$, each with $|n/m - a/q| < \delta$ for some integer $a$ and some $1 \le q \le W$, one has $\#S < \eta H$.

The proof applies the theorem of the used node `erdos-1094--h2--h2--h2--h3--h1--h1` (Konyagin's Theorem 2 as van Doorn and Tang state it): if $f$ is $C^{r+1}$ with $D_r/2 \le |f^{(r)}| \le D_r$ and $|f^{(r+1)}| \le D_{r+1}$ on $[0,N]$, then for every $\lambda \ge 1$ the integers $u \in [0, N]$ with $f(u)$ within $\delta$ of a rational of denominator at most $W$ number less than
$$65536\,N\Bigl[\bigl(D_r\lambda^rW^2\bigr)^{\frac1{2r-1}} + \Bigl(\frac{\delta W^2}{D_r\lambda^r}\Bigr)^{\frac1{r-1}} + \Bigl(\frac{D_{r+1}\lambda W^2}{D_r}\Bigr)^{\frac1{2r}}\Bigr] + 2r\lambda .$$
It is used with $f(x) = (-1)^r n/(k+x)$, $N = H$, $D_r = r!\,n/k^{r+1}$, and with $r$ and $\lambda$ chosen so that each of the three terms is at most a small constant $\tau$. The exponents $3/5$ and $1/100$ are choices; the argument needs only $21/40 < 3/5 < 1$ and a small power for $W$.

## The application to n/(k+x) {steps: h_thm hkR hk1R hnR hH hW h_x3b4 hrat happ}

This is the helper lemma `kf_app`. Let $f$ be a function that is smooth on all of $\mathbb{R}$ and equals $(-1)^r n/(k+x)$ for $x \ge -k/4$ (the construction of the node `erdos-1094--h2--h2--h2--h3--h1`, reused). For $x \ge 0$, $|f^{(j)}(x)| = j!\,n/(k+x)^{j+1}$. So on $[0,H]$: $|f^{(r)}| \le D_r$, $|f^{(r+1)}| \le D_{r+1} = (r+1)!\,n/k^{r+2}$, and $|f^{(r)}| \ge D_r/2$ as soon as $(k+H)^{r+1} \le 2k^{r+1}$. Send $m \in S$ to $u = m - k$: this is injective, $0 \le u \le \lfloor H\rfloor$, and $|f(u) - (-1)^r a/q| = |n/m - a/q| < \delta$. The theorem bounds $\#S$ by the display above with $N = H$.

## The choice of r and λ {steps: h_params s6 s7 hk1 hn1 hr2}

This is the helper lemma `kf_params`, proved from `kf_event`, `kf_PR`, `kf_choose` and `kf_conds`. Let $0 < \tau < 1$, $\ell = \log(1/\tau)$, $R = \lfloor \log k/(100\,\ell)\rfloor$ and $c = 1/(200\,\ell)$. Then $\tau^R \ge k^{-1/100}$, and for large $k$ one has $2(R+1) \le \min(\eta,1)\,k^{1/4}$ and $k^2\tau > 1$.

Call $P(r)$ the inequality $n\,r!\,W^2\tau \le \tau^{2r}k^{r+1}$. $P(R)$ holds: $n \le \exp(c\log^2 k) = k^{c\log k}$, $R! \le R^R \le k^{R/4}$, $W^2 = k^{1/50}$, $\tau^{2R} \ge k^{-1/50}$, and $c\log k + R/4 + 1/50 \le R + 1 - 1/50$ because $c\log k \le (R+1)/2$. Let $r$ be the least natural number with $P(r)$; so $r \le R$. From $n \ge k^3$, $W \ge 1$ and $k^2\tau > 1$, each of $P(0)$, $P(1)$, $P(2)$ fails, so $r \ge 3$, and $P(r-1)$ fails.

Put $Q = \tau^{2r}k^{r+1}/(n\,r!\,W^2\tau)$ and $\lambda = Q^{1/r}$. By $P(r)$, $Q \ge 1$, so $\lambda \ge 1$; and $D_r\lambda^rW^2\tau = \tau^{2r}$ exactly. Since $P(r-1)$ fails, $n\,r!\,W^2\tau > r\,\tau^{2r-2}k^r$, hence $Q \le k$ and $\lambda^3 \le \lambda^r \le k$, that is $\lambda \le k^{1/3}$. Then, with $r \le R$:

- $2rH \le k^{1/4}k^{3/5} \le k$, which gives $(k+H)^{r+1} \le 2k^{r+1}$ (the theorem's body derives this from the helper `key_ratio`: $(1+u)^{r+1} \le 2$ when $2ru \le 1$);
- first term: $D_r\lambda^rW^2 = \tau^{2r-1}$;
- second term: $\delta W^2/(D_r\lambda^r) \le \tau^{r-1}$, which is $\delta W^4\tau^2 \le \tau^{3r}$, true since $\delta W^4 = k^{-9/25} \le k^{-3/100} \le \tau^{3R} \le \tau^{3r}$;
- third term: $D_{r+1}/D_r = (r+1)/k$, and $(r+1)\lambda W^2 \le k^{1/4+1/3+1/50} \le k^{1-1/50} \le \tau^{2r}k$;
- $2r\lambda \le \eta\,k^{1/4}k^{1/3} \le \eta\,k^{3/5}$.

## Conclusion {steps: h_x3c40 h_x3c41 h_x3c4_x3b7 hD hlam0 hY hW2 hB1 hB2 hB3 h6 h7 h8 close}

Given $\eta$, take $\tau = \min(1/2,\ \eta/(6\cdot 65536))$ and apply the previous section with $\eta/2$ in place of $\eta$. Each of the three terms is at most $\tau$ (a number $x \ge 0$ with $x \le \tau^m$ has $x^{1/m} \le \tau$), so
$$\#S < 65536\,H\cdot 3\tau + \tfrac{\eta}{2}H \le \tfrac{\eta}{2}H + \tfrac{\eta}{2}H = \eta H .$$
