## Theorem

$$\exists\, G:\mathbb{C}\to\mathbb{C}\ \text{continuous on}\ \{\operatorname{Re} s \ge 1\}\ \text{with}\ G(s) = \sum_{n\ge 1}\frac{\Lambda(n)}{n^{s}} - \frac{1}{s-1}\ \text{for}\ \operatorname{Re} s > 1.$$

 The Dirichlet series of the von Mangoldt function minus its pole at $s = 1$ extends continuously to the closed half-plane $\operatorname{Re} s \ge 1$: there is a function $G$, continuous on $\{s : \operatorname{Re} s \ge 1\}$, with $G(s) = L(\Lambda, s) - 1/(s-1)$ whenever $\operatorname{Re} s > 1$.

## Proof

 For $\operatorname{Re} s > 1$ the series $L(\Lambda, s) = \sum_n \Lambda(n) n^{-s}$ converges and equals $-\zeta'(s)/\zeta(s)$. The function $\zeta$ is meromorphic with a single simple pole, at $s = 1$, of residue $1$, and it does not vanish on the closed half-plane $\operatorname{Re} s \ge 1$ (for $\operatorname{Re} s > 1$ by the Euler product, on the line $\operatorname{Re} s = 1$ by the Hadamard–de la Vallée Poussin argument). Hence $-\zeta'/\zeta$ is holomorphic on $\operatorname{Re} s \ge 1$ except for a simple pole of residue $1$ at $s = 1$, so $-\zeta'(s)/\zeta(s) - 1/(s-1)$ has a removable singularity there and is continuous on the whole closed half-plane. Taking $G$ to be that continuous extension proves the theorem.

## The formal proof

 All of this is already in Mathlib, in the generality needed for Dirichlet's theorem on primes in arithmetic progressions. For a modulus $q$ and a residue class $a \bmod q$, Mathlib defines
`ArithmeticFunction.vonMangoldt.LFunctionResidueClassAux a : ℂ → ℂ`, proves it continuous on $\{\operatorname{Re} s \ge 1\}$ (`continuousOn_LFunctionResidueClassAux`), and proves that for a unit $a$ it agrees on $\operatorname{Re} s > 1$ with $L(\Lambda\cdot 1_{n \equiv a}, s) - \varphi(q)^{-1}/(s-1)$ (`eqOn_LFunctionResidueClassAux`). The proof takes $q = 1$ and $a = 1$, the only element of `ZMod 1`, which is a unit. Then the residue class is all of $\mathbb{N}$, so `vonMangoldt.residueClass 1 n = Λ n` for every $n$ (the defining set `{n | (n : ZMod 1) = 1}` is everything, because `ZMod 1` is a subsingleton), and $\varphi(1) = 1$, so $\varphi(1)^{-1} = 1$. Rewriting with these two facts turns Mathlib's identity into the one the statement asks for, with $G$ := `LFunctionResidueClassAux (1 : ZMod 1)`. No analytic estimate is redone; the content is Mathlib's non-vanishing of $\zeta$ on $\operatorname{Re} s = 1$ and its residue at $1$, packaged behind that one definition. $\blacksquare$

## Where it sits

 This is one of the two inputs of the prime number theorem for $\psi$ along the Wiener–Ikehara route (the parent node): with $f = \Lambda$ and $A = 1$, the Tauberian theorem (the sibling hole) turns this continuity into $\sum_{n < N} \Lambda(n) / N \to 1$, which is $\psi(x) \sim x$.
