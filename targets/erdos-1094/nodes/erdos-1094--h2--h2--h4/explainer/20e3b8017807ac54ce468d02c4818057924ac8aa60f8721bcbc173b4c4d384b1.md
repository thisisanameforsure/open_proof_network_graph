## The argument

Throughout $H = k^{3/5}$ and $W = k^{1/100}$. The theorem's body applies one lemma, `KF_final`, to the three holes; what follows is the proof of that lemma, in the helper lemmas that precede the theorem in the file.

**The three inputs.** (BHP, hole `h_bhp`) There are $C > 0$ and $k_0$ such that $(k, k + k^{21/40})$ holds at least $C k^{21/40}/\log k$ primes for every $k \ge k_0$. (Supply, `h_supply`) Either BHP fails, or there is $c_1 > 0$ such that for every large $k$ at least $c_1 H$ integers $m$ with $k < m \le k + H$ are products $m = qp$ with $2 \le q \le W$ and $p$ prime. (Count, `h_count`) For every $\eta > 0$ there is $c > 0$ such that for every large $k$ and every $n$ with $k^3 \le n \le \exp(c\log^2 k)$, fewer than $\eta H$ integers $m$ with $k < m \le k + H$ have $|n/m - a/q| < H/k$ for some integer $a$ and some natural $1 \le q \le W$.

**A prime just above $k/q$** (`KF_carry`). Let $p$ be prime, $q \ge 2$ and $(q-1)p \le k < qp$, and put $m = qp$. Then $k \bmod p = k - (q-1)p$. If $n \bmod p < k \bmod p$, Lucas' theorem gives $\binom nk \equiv \binom{n \bmod p}{k \bmod p}\binom{\lfloor n/p\rfloor}{\lfloor k/p\rfloor} \equiv 0 \pmod p$, so $p \mid \binom nk$. Otherwise $n \bmod p \ge k - (q-1)p$; write $n = dp + (n \bmod p)$ and $a = d + 1$. Then

$$\frac nm - \frac aq = -\frac{p - (n \bmod p)}{m}, \qquad 0 < p - (n \bmod p) \le qp - k = m - k,$$

so $|n/m - a/q| \le (m - k)/m$.

**The size of $p$** (`KF_range`). If $k \ge 1$, $2 \le q \le W$ and $k < qp \le k + H$, then $qH \le WH = k^{61/100} \le k < qp$, so $p > H$ and $qp \le k + H < k + p$, that is $(q-1)p \le k$.

**Assembly** (`KF_final`). Take $c_1$ from `h_supply` (BHP holds), then $c$ from `h_count` with $\eta = c_1$. Let $k$ be large, $k^3 \le n \le \exp(c\log^2 k)$, and let $S$ be the set of at least $c_1 H$ products $m = qp$ in $(k, k + H]$. Suppose no prime $p \le k$ divides $\binom nk$. For each $m = qp$ in $S$ the previous two paragraphs apply, and $p \le (q-1)p \le k$, so the first alternative of `KF_carry` is excluded; hence $|n/m - a/q| \le (m-k)/m < H/k$, the last step because $m - k \le H$ and $m > k$. So every element of $S$ is counted by `h_count`, which gives $\#S < c_1 H \le \#S$, a contradiction. Hence some prime $p \le k$ divides $\binom nk$.
