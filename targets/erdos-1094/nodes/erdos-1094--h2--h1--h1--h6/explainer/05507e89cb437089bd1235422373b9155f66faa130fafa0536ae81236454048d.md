## The proof

Write $\theta = 21/40$ and let BHP be the first alternative's hypothesis: for some $C > 0$ and all large $k$, the interval $(k, k + k^{\theta})$ holds at least $C k^{\theta}/\log k$ primes. If BHP fails, the first alternative holds and nothing is left to prove; this is the Lean's `by_cases`. So assume BHP. The claim is then: for all large $k$ and all $n$ with
$$2k \le n \le \tfrac12 (k/2)^{2-\theta} + 2k$$
there is a prime $p$ with $k < 2p$ and $(n \bmod p) + p < k$. The work is in six helper lemmas placed before the theorem; they are described here in the order of the argument.

### Two multiples in the window (`sm_carry_of_mult`)

Let $p \ge 1$ and $j$ be natural numbers with
$$n - k < j\,p \qquad\text{and}\qquad (j+1)\,p \le n .$$
Then $(n \bmod p) + p < k$. Indeed $\lfloor n/p \rfloor \ge j+1$, so $n \bmod p = n - p\lfloor n/p\rfloor \le n - (j+1)p$, and $n - (j+1)p + p = n - jp < k$. So it is enough to find a prime $p > k/2$ and a $j$ for which the two multiples $jp$ and $(j+1)p$ lie in $(n-k, n]$.

### A prime in every short window (`sm_window`)

*For all large natural $K$ and every real $a$ with $K \le a \le K + 3K^{\theta}$ there is a prime $p$ with $a < p < a + K^{\theta}$.*

This is the window lemma of van Doorn and Tang's small-range proof (the node `erdos-1094--h2--h2--h2--h1`) with $3K^{\theta}$ where they have $2K^{\theta}$, and the proof is theirs. Put $N = \lceil a \rceil$, so $K \le N \le K + 3K^{\theta} + 1$. BHP at $N$ gives at least $C N^{\theta}/\log N$ primes in $(N, N + N^{\theta})$. Moving the right end of an interval down from $N + N^{\theta}$ to $a + K^{\theta}$ loses at most (length moved) $+\,1$ primes, which is at most $N^{\theta} - K^{\theta} + 2$. By subadditivity of $x \mapsto x^{\theta}$,
$$N^{\theta} - K^{\theta} \le (N - K)^{\theta} \le (4K^{\theta})^{\theta} = 4^{\theta} K^{\theta^{2}} .$$
Since $\theta^{2} < \theta$, the loss $4^{\theta}K^{\theta^{2}} + 2$ is smaller than $C N^{\theta}/\log N$ for large $K$ (here $N \le 5K$ and $\log N \le 2\log K$ are used to compare $N$ with $K$). So a prime remains in $(N, a + K^{\theta})$, and $N \ge a$.

### The two cases (`sm_caseA`, `sm_caseB`, `sm_core`)

Let $K = \lfloor k/2 \rfloor$, so $K \le k/2 \le K + \tfrac12$, let $h = K^{\theta} \ge 1$, and let $J = \lfloor 2n/k \rfloor$, so that
$$J k \le 2n < (J+1) k , \qquad J \ge 4 .$$
Assume also the size condition $h\,(J+1) \le k/2$, proved in the last step.

**Case A: $J(k + 2h) \le 2n$.** Take a prime $p$ with $k/2 < p < k/2 + h$ (window lemma at $a = k/2$). Then $J p < J(k/2 + h) \le n$, and $(J-1)\,p > (J-1)k/2 > n - k$ because $2n < (J+1)k$. So $j = J - 1$ works.

**Case B: $2n < J(k + 2h)$.** Put $a = (n-k)/(J-2)$. From $Jk \le 2n$ we get $a \ge k/2 \ge K$. From the case hypothesis, $(J-2)\,a = n - k < (J-2)k/2 + J h$, and since $k/2 \le K + \tfrac12$, $h \ge 1$ and $J - 2 \ge 2$ this gives $a \le K + 3h$. Take a prime $p$ with $a < p < a + h$. Then $p > k/2$ and $(J-2)\,p > n - k$. For the other multiple,
$$(J-1)\,p < (J-1)(a + h), \qquad (J-1)(a+h) \le n \iff n + (J-1)(J-2)\,h \le (J-1)\,k ,$$
and the right-hand inequality follows from $2n < J(k + 2h)$ and $h(J+1) \le k/2$: it reduces to $J + (J-1)(J-2) \le (J-2)(J+1)$, that is $J \ge 4$. So $j = J - 2$ works.

In both cases $p > k/2$, which is $k < 2p$.

### The size condition (`sm_small_gen`)

Write $x = k/2$. From $J k \le 2n \le x^{2-\theta} + 4k$ and $k = 2x$ we get $J \le \tfrac12 x^{1-\theta} + 4$. Also $h = K^{\theta} \le x^{\theta}$. Hence
$$h\,(J+1) \le x^{\theta}\bigl(\tfrac12 x^{1-\theta} + 5\bigr) = \tfrac{x}{2} + 5x^{\theta} \le x$$
as soon as $x^{1-\theta} \ge 10$, which holds for all large $k$ because $x^{1-\theta} \to \infty$. The threshold $k_0$ is the larger of this bound and twice the window lemma's threshold (plus 2), so that $K$ is past the latter.

### On the range

Van Doorn and Tang's small range for primes above $k$ is $n \le \tfrac12 k^{2-\theta}$. Here the window of Case B starts at the exact lower end $a = (n-k)/(J-2)$ of the interval of primes having the two multiples $(J-2)p$, $(J-1)p$ in $(n-k, n]$; the argument above needs only $h(J+1) \le k/2$, which holds for $n \le c\,(k/2)^{2-\theta}$ with any fixed $c < 1$ and large $k$. The stated bound $\tfrac12 (k/2)^{2-\theta} + 2k$ is the one the parent's assembly uses.
