Dyadic sub-case of Erdős #69: what rationality with a power-of-two denominator would force, and why it is still the hard part.

Notation. Let x = sum over n >= 0 of omega(n)/2^n (the root's series: omega(0) = omega(1) = 0, so dropping n = 0, 1 changes nothing) and, for N >= 0, the tail T_N = sum over j >= 0 of omega(N+1+j)/2^(j+1). The proved hole erdos-69--h1-v2 identifies x with the sum over primes p of 1/(2^p - 1).

Step 1 (fast-checked, not gate-checked). If x = a/2^m with a an integer, then T_N is an integer for every N >= m, because T_N = 2^N x - sum over i <= N of omega(i) 2^(N-i). Step 2 (informal, not machine-checked). From T_(N-1) = omega(N)/2 + T_N/2 we get T_N = 2 T_(N-1) - omega(N), so by induction, for N >= m + k,
T_N = 2^k T_(N-k) - S, where S = sum over i < k of 2^i omega(N - i),
hence T_N is congruent to -S modulo 2^k. In particular T_N has the parity of omega(N). The proved holes erdos-69--h2-v2--h1-v2--h2 and --h3 give 0 < T_N <= log2(N+1) + 1 =: L. So once 2^k > L, a contradiction follows from a single window of k consecutive integers ending at N with S mod 2^k outside [2^k - floor(L), 2^k - 1]; S divisible by 2^k is enough.

Why this does not settle even the dyadic case. k must be about log2 log2 N, and the condition asks for the binary-weighted pattern of omega on k consecutive integers near N to avoid a set of about L out of 2^k residues. The Chinese remainder theorem prescribes small prime factors of N-k+1, ..., N but not their large ones, so it does not control S modulo 2^k, and even the parity of omega along consecutive integers is a Chowla-type question. This is the b = 1 instance of erdos-69--h2-v2--h1-v2--h4, which merged defect claims show is no easier than the root; this note records that restricting to power-of-two denominators does not make it elementary, so that the next contributor does not re-derive the reduction. The known proof (per the approach records on this target: Tao and Teräväinen, 2025) is not formalized here; I could not re-check its details in this session.
