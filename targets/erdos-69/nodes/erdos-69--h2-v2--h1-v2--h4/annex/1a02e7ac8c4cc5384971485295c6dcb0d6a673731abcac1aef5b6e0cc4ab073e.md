The hole erdos-69--h2-v2--h1-v2--h4 is equivalent to the target: this skeleton does not reduce the problem

Status: an informal argument, not machine-checked. Author: t0923-69-b, 2026-09-23.

Notation: S = sum over n >= 0 of omega(n)/2^n, T(N) = sum over j >= 0 of omega(N+1+j)/2^(j+1), and for N, k the window integer A(N,k) = sum_{j<k} omega(N+1+j) * 2^(k-1-j), so that T(N) = A(N,k)/2^k + T(N+k)/2^k (hole h1 of this parent). The conclusion of h4 is: for every b > 0 there are N, k with (b*A mod 2^k) + b*(log2(N+k+1)+1) < 2^k.

1. h4 implies the target. This is the parent's assembly, as the earlier annex on erdos-69--h2-v2--h1-v2 explains: if b*T(N) = z were an integer, then b*A + b*T(N+k) = z*2^k with 0 < b*T(N+k) <= b*(log2(N+k+1)+1) (holes h2 and h3), which puts z*2^k strictly between floor(b*A/2^k)*2^k and the next multiple of 2^k.

2. The target implies h4, with N = 0. Suppose b*S is not an integer and let f in (0,1) be its fractional part. T(0) = S (earlier annex, fact 2). By h1, b*A(0,k)/2^k = b*S - g_k where g_k = b*T(k)/2^k, and by h3, 0 < g_k <= b*(log2(k+1)+1)/2^k, which tends to 0. For k large enough that g_k < f, floor(b*A/2^k) = floor(b*S), so b*A mod 2^k = 2^k*(f - g_k). Then (b*A mod 2^k) + b*(log2(k+1)+1) = 2^k*(f - g_k) + b*(log2(k+1)+1) < 2^k as soon as b*(log2(k+1)+1)/2^k < 1 - f, which holds for all large k.

3. Conversely, if b*S is an integer z then for every N the inequality fails at every k (the earlier annex's integrality_step: b*T(N) is then an integer for all N, and the display in 1 is violated). So for each b, h4 at b holds if and only if b*S is not an integer, and h4 as a whole holds if and only if S is irrational.

Consequence for provers: no choice of N and k can be exhibited for general b without, in effect, proving that S is irrational; every piece of the difficulty of Erdős 69 sits in h4, and the skeleton at erdos-69--h2-v2--h1-v2 converts the problem into an equivalent one plus three routine lemmas (h1, h2, h3, whose proofs I submitted on 2026-09-23). A proof of h4 needs genuinely arithmetic input: for instance an argument in the style of Erdős's proofs for Lambert series, choosing N by the Chinese remainder theorem so that omega is forced large on chosen positions of a window, together with a bound on the size of N that such a choice costs (log2 N must stay below roughly 2^k / b). A rival skeleton for erdos-69--h2-v2 that states that arithmetic lemma directly, rather than h4, would be a real reduction.
