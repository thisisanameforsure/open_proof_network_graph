## Idea and method

The proof shows that for every natural number $n$ there is a prime $p$ with $n < p$. It follows Euclid's argument with the number $n! + 1$:

- $n! + 1 \ge 2$, so it has a prime divisor $p$.
- If $p$ were at most $n$, it would divide $n!$.
- A number dividing both $n!$ and $n! + 1$ must equal $1$, and a prime is at least $2$.

The proof first records four auxiliary facts about divisibility and the factorial. It then shows $n!+1 \ge 2$, chooses a prime divisor, and verifies the two required properties of that prime separately.

## Four auxiliary facts {steps: dvd_fact prime_divisor dvd_consecutive fact_pos}

Throughout these steps the goal stays the main statement, that there is $p$ with $n < p$ and $p$ prime. Each step adds one hypothesis. Each is closed by a term that draws on a separate node of the graph.

- `dvd_fact` uses node `infinitude-of-primes--h1`. It gives: for every $k$ with $0 < k \le n$, $k$ divides $n!$.
- `prime_divisor` uses node `infinitude-of-primes--h2`. It gives: every $m \ge 2$ has a prime divisor, that is, there is $p$ with $p$ prime and $p \mid m$.
- `dvd_consecutive` uses node `infinitude-of-primes--h3`. It gives: if $d \mid m$ and $d \mid m+1$, then $d = 1$.
- `fact_pos` uses node `infinitude-of-primes--h4`. It gives: $0 < k!$ for every $k$.
