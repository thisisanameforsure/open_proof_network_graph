Informal proof of spec-f2b55478 (the Pade remainder coefficient identity) by partial fractions.
Not machine-checked; the identity and the two intermediate identities below were checked exactly
in rational arithmetic (Python fractions, with Lean's truncated nat subtraction reproduced) for
0 <= n <= 5, n < m <= n+8 (the full identity) and 0 <= n <= 7, 0 <= j <= n (the residue identity).

Notation. q = 2, (q;q)_r = prod_{s=1..r} (2^s - 1), [n j] the 2-binomial, x = 2^m, and
  c_j = (-1)^j 2^{j(j-1)/2} [n j] prod_{i<n} (2^{2n-j-i} - 1)/(2^{i+1} - 1)   (the LHS coefficient).
Let D(x) = prod_{k=0..n} (x - 2^k)  (monic, degree n+1, simple roots 2^0..2^n)
and N(x) = prod_{i=0..n-1} (x - 2^{n+1+i})  (monic, degree n).

1. LHS. Since 2^{m-j} - 1 = (x - 2^j)/2^j and m > n >= j, each term is c_j 2^j / (x - 2^j), so
   LHS = sum_j c_j 2^j / (x - 2^j).

2. RHS = N(x)/D(x). Write 2^{m-n-1-i} - 1 = (x - 2^{n+1+i}) / 2^{n+1+i} and 2^{m-j} - 1 = (x - 2^j)/2^j.
   The two products of (2^{i+1} - 1) cancel, and the powers of 2 cancel exactly:
   n^2 - sum_{i<n}(n+1+i) + sum_{j<=n} j = n^2 - (n^2 + n(n+1)/2) + n(n+1)/2 = 0.
   Lean's truncation of m-n-1-i is harmless: it happens only when n < m <= 2n, and then the factor
   i = m-n-1 is 2^0 - 1 = 0 on both readings, so both sides of RHS = N(x)/D(x) are 0.

3. Partial fractions. deg N < deg D and D has simple roots, so
   N(x)/D(x) = sum_{j=0..n} N(2^j) / D'(2^j) / (x - 2^j),  D'(2^j) = prod_{k<=n, k != j} (2^j - 2^k).
   Equivalently (clearing denominators) sum_j N(2^j)/D'(2^j) * prod_{k != j}(X - 2^k) = N(X) is
   Lagrange interpolation of the degree-n polynomial N at the n+1 nodes 2^0..2^n
   (Mathlib: Lagrange.interpolate / Lagrange.eq_interpolate_of_eval_eq, nodes injective since 2^k is).

4. Residue identity: c_j 2^j = N(2^j) / D'(2^j). Compute
   N(2^j) = (-1)^n 2^{jn} prod_{i<n} (2^{n+1+i-j} - 1), and the exponents n+1-j..2n-j are exactly
   those of prod_{i<n}(2^{2n-j-i} - 1) in c_j.
   D'(2^j) = [prod_{k<j} 2^k (2^{j-k} - 1)] [prod_{j<k<=n} (-2^j)(2^{k-j} - 1)]
           = (-1)^{n-j} 2^{j(j-1)/2 + j(n-j)} (q;q)_j (q;q)_{n-j}.
   So N(2^j)/D'(2^j) = (-1)^j 2^{j(j+1)/2} [n j] prod_{i<n}(2^{2n-j-i}-1) / (q;q)_n = c_j 2^j,
   using j(j-1)/2 + j = j(j+1)/2 and [n j] = (q;q)_n / ((q;q)_j (q;q)_{n-j}).

Steps 1-4 give LHS = RHS for every n < m. A Lean proof would most likely go: cast to x = 2^m,
multiply out by D(x) (all factors nonzero because m > n), and reduce to the polynomial identity of
step 3 evaluated at x, with the coefficient computation of step 4 done by Finset.prod_range_succ
induction or by splitting prod_{k != j} at j.
