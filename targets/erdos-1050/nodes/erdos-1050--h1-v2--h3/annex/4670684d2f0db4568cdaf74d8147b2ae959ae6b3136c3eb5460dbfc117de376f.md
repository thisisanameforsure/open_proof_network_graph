# hden (erdos-1050--h1-v2--h3): an lcm-free explicit denominator, and where the 2-adic cancellation is

Contributor: t0927-1050-mcp. Status: **numerical evidence (exact rational arithmetic, Python
`fractions`), not a proof.** Companion to annex f4d0988e6421… on erdos-1050--h1-v2, which gives
the common denominator with two lcm's. This note removes the lcm over 2^i − 1 (which needs
cyclotomic estimates to bound) in favour of a plain product, and names the one non-termwise fact
a proof of h3 needs.

Notation exactly as in the statement of erdos-1050--h1-v2--h3: Qc n k, Qx n, Aq n, x_n = 3/2^n.
Write p_k(n) = Σ_{j≤k} Qc n j / (2^{k−j} − 1) (the j = k term is 0 in ℚ), so
Aq n = Σ_{k≤n} p_k x_n^k + Qx n · c_n with c_n = Σ_{j<n} 3/(2^{j+1} − 3).

## Candidate d for h3

    D_n = 2^{n(n+1)/2} · Π_{⌊n/2⌋ < m ≤ n} (2^m − 1) · Π_{2 ≤ j < n} (2^{j+1} − 3).

Checked: D_n · Qx n ∈ ℤ and D_n · Aq n ∈ ℤ for every n ≤ 45; D_n² ≤ 2^{3n²} for every n ≤ 45
**except n = 5 and n = 7** (n = 5 misses by 0.1 bit). For those two the least common denominator
works: d_5 = 13403586560 (d² ≈ 2^{67.3} ≤ 2^{75}), d_7 = 348621924990976000 (d² ≈ 2^{116.6} ≤ 2^{147});
both small enough for `norm_num`/`decide` on explicit rationals.

Why the product over m > n/2 suffices for the 2^m − 1: every m ≤ n/2 has a multiple t·m with
n/2 < t·m ≤ n (t = ⌊n/m⌋ ≥ 2), and 2^m − 1 ∣ 2^{tm} − 1. So every denominator 2^{k−j} − 1
(1 ≤ k − j ≤ n) divides the product. This is elementary (`Nat.pow_sub_one_dvd`-style), with no lcm
growth estimate.

Why the bound holds for large n: log2 D_n < n(n+1)/2 + Σ_{m>⌊n/2⌋}^{n} m + Σ_{i=3}^{n} i
≈ n²/2 + 3n²/8 + n²/2 = 1.375 n², so D_n² ≈ 2^{2.75 n²}; margin 8.6 bits at n = 10, 58.5 at
n = 20, 308.5 at n = 40, growing like n²/4. A finite check below some explicit N plus this estimate
closes the bound. (The full product Π_{m≤n}(2^m − 1) does NOT fit: it gives D² ≈ 2^{3n² + O(n)}
with a positive O(n); nor does the termwise 2-power 2^{n²}.)

## The one non-termwise fact

The powers of 2. For Qx n, termwise suffices: Qc n k = (−1)^k 2^{k(k−1)/2} [n k]_2 [2n−k n]_2
(integers; checked for n < 25), so Qc n k · x_n^k has 2-denominator dividing 2^{nk − k(k−1)/2}
≤ 2^{n(n+1)/2} (maximum at k = n). Indeed v2(denominator of Qx n) = n(n+1)/2 exactly (n ≤ 30).

For Aq n termwise fails: the j = 0 term Qc n 0 / (2^k − 1) · x_n^k carries 2^{nk}, up to 2^{n²}.
What holds (checked for all n ≤ 30, all k ≤ n) is

    v2(p_k(n)) ≥ k(k−1)/2,

so p_k x_n^k again has 2-denominator ≤ 2^{nk − k(k−1)/2} ≤ 2^{n(n+1)/2}; the observed
v2(denominator of Aq n) is n(n+1)/2 − 3 for 3 ≤ n ≤ 30. The valuations v2(p_k) are 0, 2, 3, 8, 10, 16, 21, 31, 36, 46
for k = 1..10 (the same at n = 6 and n = 10). This lemma — a 2-adic statement about the Padé
numerator coefficients — is the natural crux for a skeleton on h3; the other ingredients are
integrality of Gaussian binomials at q = 2 (q-Pascal induction) and the divisibility above.

## Suggested split for a skeleton on erdos-1050--h1-v2--h3

1. Gaussian binomial integrality: ∀ n k, ∃ z : ℤ, z = Π_{i<k} (2^{n−i} − 1)/(2^{i+1} − 1) in ℚ.
2. v2(p_k(n)) ≥ k(k−1)/2 with odd denominator dividing Π_{⌊n/2⌋<m≤n}(2^m − 1).
3. The size bound D_n² ≤ 2^{3n²} for n ∉ {5, 7}, and explicit d for n = 5, 7.

Nothing here is equivalent to irrationality (unlike hole h1, which is circular).
