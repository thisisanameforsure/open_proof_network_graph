This file states and proves a theorem named `witness`: there exist functions $Q_c:\mathbb N\times\mathbb N\to\mathbb Q$, $Q_x:\mathbb N\to\mathbb Q$, $A_q:\mathbb N\to\mathbb Q$ and a natural number $n$ such that

- $Q_c(n,k)=(-1)^k\,2^{k(k-1)/2}\prod_{i<k}\frac{2^{n-i}-1}{2^{i+1}-1}\prod_{i<n}\frac{2^{2n-k-i}-1}{2^{i+1}-1}$ for all $n,k$,
- $Q_x(n)=\sum_{k=0}^{n}Q_c(n,k)(3/2^n)^k$ for all $n$, and
- $A_q(n)=\sum_{k=0}^{n}\big(\sum_{j=0}^{k}\frac{Q_c(n,j)}{2^{k-j}-1}\big)(3/2^n)^k+Q_x(n)\sum_{j<n}\frac{3}{2^{j+1}-3}$ for all $n$.

These are the three hypotheses of the statement of this node, written exactly as there (as equations between functions), so the theorem says those hypotheses can all hold at once. The existentially quantified $n$ appears in none of the three equations; the statement's own $n$ is quantified after the hypotheses and has no counterpart here.

The proof takes for $Q_c$, $Q_x$ and $A_q$ the functions the formulas define, and $n=0$; each equation then holds by definition (`rfl`).
