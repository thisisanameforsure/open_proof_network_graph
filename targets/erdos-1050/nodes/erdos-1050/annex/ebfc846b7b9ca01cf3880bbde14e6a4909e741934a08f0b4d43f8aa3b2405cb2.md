Informal argument for Erdős problem 1050: the irrationality of S = ∑_{n ≥ 0} 1/(2^(n+1) − 3).

1. Reindexing. The n = 0 term is 1/(2 − 3) = −1 and the n = 1 term is 1/(4 − 3) = 1, so S equals the tail T = ∑_{n ≥ 0} 1/(2^(n+3) − 3) = 1/5 + 1/13 + 1/29 + …, every term of which is positive. The series is summable: for n ≥ 0, 2^(n+3) − 3 = 8·2^n − 3 ≥ 2^n, so 0 < 1/(2^(n+3) − 3) ≤ (1/2)^n.

2. Irrationality criterion (Dirichlet-type). If x is real and there are integer sequences a_n, b_n with b_n·x − a_n ≠ 0 for every n and b_n·x − a_n → 0, then x is irrational: for x = p/q with q ≥ 1, q·(b_n·x − a_n) = b_n·p − a_n·q is a nonzero integer, so |b_n·x − a_n| ≥ 1/q for every n, contradicting the limit.

3. Borwein's theorem (P. B. Borwein, On the irrationality of ∑ 1/(q^n + r), J. Number Theory 37 (1991) 253–259; self-contained proof in Math. Proc. Camb. Phil. Soc. 112 (1992) 141–146), specialised to q = 2, r = −3: Padé-type approximants to the q-series give integer sequences a_n, b_n with b_n·T − a_n ≠ 0 and b_n·T − a_n → 0. This is the single hole of the skeleton; steps 1 and 2 are proved in the assembly.
