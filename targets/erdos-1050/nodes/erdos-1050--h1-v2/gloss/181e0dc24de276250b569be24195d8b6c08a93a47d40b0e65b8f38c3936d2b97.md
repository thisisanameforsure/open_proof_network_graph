This file states the theorem `erdos_1050__h1`. Write
$\displaystyle T = \sum_{m=0}^{\infty} \frac{1}{2^{m+3}-3} = \frac15 + \frac1{13} + \frac1{29} + \cdots,$
a real number (Lean's `∑'` over all natural numbers $m$, with real division). The statement says:

there are two sequences of integers $a, b : \mathbb{N} \to \mathbb{Z}$ such that

1. for every natural number $n$, $b_n T - a_n \neq 0$ (the integers $a_n, b_n$ are read as real numbers here), and
2. $b_n T - a_n \to 0$ as $n \to \infty$ (Mathlib's `Filter.Tendsto … Filter.atTop (nhds 0)`: the sequence converges to $0$ in $\mathbb{R}$).

Nothing else is assumed: the statement has no hypotheses.

Reading notes:

- In the Lean text the summation variable inside `∑'` is also called `n`. It is a separate bound variable, so $T$ does not depend on the outer $n$; above it is renamed $m$.
- No denominator $2^{m+3}-3$ is zero (the smallest is $5$), so Lean's convention that division by zero gives $0$ never applies. The statement does not itself assert that the series converges, and Lean defines the `tsum` of a non-summable family to be $0$; this series converges (its terms are at most $\tfrac15 \cdot 2^{-m}$), so $T$ is its ordinary sum.
- The file does not mention irrationality. A pair of sequences as above is the classical criterion for $T$ to be irrational, which is how the root node `erdos-1050` uses this statement.
