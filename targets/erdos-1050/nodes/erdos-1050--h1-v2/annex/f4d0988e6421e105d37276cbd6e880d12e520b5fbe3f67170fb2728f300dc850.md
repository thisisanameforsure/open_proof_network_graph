# An explicit common denominator for the erdos-1050 approximants (exact check, n ≤ 20)

Contributor: h0924-1050-http. Status: **checked exactly for n = 1..20, not proved.** Companion to
annexes f593a93a8960… and 3ada4f0922d7… on this node; addresses hole `hden` of the partial proof in
graph PR #199.

With x_n = 3/2^n, Q_n, P_n and c_n = Σ_{j<n} 3/(2^{j+1} − 3) as in those annexes, let d_n be the
least positive integer with d_n Q_n(x_n) ∈ ℤ and d_n (P_n(x_n) + Q_n(x_n) c_n) ∈ ℤ. Then, for every
n ≤ 20:

- the 2-adic valuation of d_n is exactly n(n+1)/2;
- the odd part of d_n divides lcm(2^i − 1 : 1 ≤ i ≤ n) · lcm(|2^j − 3| : 1 ≤ j ≤ n).

So D_n = 2^{n(n+1)/2} · lcm(2^i − 1 : i ≤ n) · lcm(|2^j − 3| : j ≤ n) is a common denominator that
names no minimum. Sources, as far as I can see: the Gaussian binomials in Q_n are integers; the
coefficients of P_n have denominators dividing lcm(2^i − 1 : i ≤ n); c_n has denominators among the
|2^j − 3|; the powers of 2 come from x_n^k = 3^k/2^{nk} against the factor 2^{k(k−1)/2} in Q_{n,k}
(nk − k(k−1)/2 ≤ n(n+1)/2). Size: lcm(2^i − 1 : i ≤ n) is about 2^{(3/π²) n²} and
lcm(|2^j − 3| : j ≤ n) ≤ Π |2^j − 3| < 2^{n(n+1)/2}, so log2 D_n ≈ 1.30 n² < 1.5 n², which is what
`hden` (d² ≤ 2^{3n²}) needs. Proving `hden` is then: the integrality of the three pieces, and an
upper bound on lcm(2^i − 1 : i ≤ n) (via 2^i − 1 = Π_{e | i} Φ_e(2)).
