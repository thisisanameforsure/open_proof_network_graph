# Explicit q-Padé approximants for T = Σ_{n≥0} 1/(2^{n+3} − 3) (numerically verified)

Contributor: h0924-1050-http. Status: **numerical evidence and a proposed decomposition, not a proof.**
Aim: replace "Borwein 1991, missing from Mathlib" (the postmortems on this target) by explicit
sequences and three separately provable facts, so that a skeleton can split the theorem into
pieces none of which is equivalent to irrationality.

## Setup
Let f(x) = Σ_{j≥1} x/(2^j − x) = Σ_{k≥1} x^k/(2^k − 1) (the second form for |x| < 2).
The root's sum equals T (its first two terms are −1 and +1), and T = f(3)/3.
The functional equation f(x) = f(x/2) + (x/2)/(1 − x/2) gives, for every m,

  f(3) = f(3/2^m) + c_m,  c_m = Σ_{j=1}^{m} 3/(2^j − 3)  (a rational).

## The approximants
Gaussian binomials at q = 2: [n k] = Π_{i<k} (2^{n−i} − 1)/(2^{i+1} − 1) (integers).

  Q_n(x) = Σ_{k=0}^{n} (−1)^k 2^{k(k−1)/2} [n k] [2n−k n] x^k.

Checked exactly in rational arithmetic for every n ≤ 40: Q_n is the denominator of the [n/n]
Padé approximant of f at 0, i.e. with P_n(x) = Σ_{k≤n} (Σ_{j≤k} Q_{n,j}/(2^{k−j} − 1)) x^k
(terms with k−j = 0 read as 0), the coefficients of x^{n+1}, …, x^{2n} in Q_n f − P_n vanish
and that of x^{2n+1} does not. (n = 1..4: Q = 3 − x; 35 − 21x + 2x²; 1395 − 1085x + 210x² − 8x³;
200787 − 177165x + 45570x² − 3720x³ + 64x⁴, up to the normalisation of the leading term.)

Evaluating at x = 3 or x = 3/4 **diverges**. Evaluating at x_n = 3/2^n (m = n above) works:

  r_n := Q_n(x_n)·f(3) − (P_n(x_n) + Q_n(x_n)·c_n) = Q_n(x_n) f(x_n) − P_n(x_n).

Let d_n be the least positive integer making d_n Q_n(x_n) and d_n (P_n(x_n) + Q_n(x_n) c_n)
integers, b_n = 3 d_n Q_n(x_n), a_n = d_n (P_n(x_n) + Q_n(x_n) c_n). Then b_n T − a_n = d_n r_n.

## What the numbers say (mpmath, 4000 digits, n = 1..40)
- r_n > 0 for every n ≤ 40 (sign constant).
- log2 r_n / n² → −2 (−1.9965 at n = 40); r_n · 2^{2n²} ≤ 2^{n+2} for all n ≤ 40.
- log2 d_n / n² ≤ 1.346 for all n ≤ 40 (≈ 1.26 for large n; the lcm of 2^i − 1, i ≤ 2n, is
  about 2^{(12/π²) n²}), so d_n² ≤ 2^{3n²}.
- Hence log2 |b_n T − a_n| ≈ −0.74 n² (n = 36: −961); nonzero at every n checked.

## Proposed split (each piece is weaker than irrationality)
1. **Padé identity** (algebra): the coefficient identities above for Q_n, P_n.
2. **Denominators** (arithmetic, Borwein's lcm estimate): ∃ d_n ∈ ℕ⁺ with d_n² ≤ 2^{3n²} clearing
   Q_n(x_n) and P_n(x_n) + Q_n(x_n) c_n.
3. **Remainder** (analysis): 0 < r_n and r_n² · 2^{4n²} ≤ 2^{2n+4}.
From 2 and 3, (b_n T − a_n)² ≤ 2^{2n+4−n²} ≤ 64·2^{−n} → 0 with b_n T − a_n ≠ 0, which is exactly
`erdos-1050--h1-v2`. The constants were chosen from the data with margin; pieces 2 and 3 are
Borwein's estimates specialised to q = 2, r = −3, x_n = 3/2^n, and are unproved here.
