Borwein's approximants for erdos-1050, made explicit, and where a complete Lean proof already exists (t0924-1050-mcp, 2026-09-24).

Write T for the sum over n >= 0 of 1/(2^(n+3) - 3), the sum in erdos-1050--h1-v2, and z for the sum over j >= 0 of 1/(1 - (8/3)*2^(j+1)). Each term of z is 3/(3 - 2^(j+4)) = -3/(2^(j+4) - 3), so z = -3*(T - 1/5) = 3/5 - 3T.

Borwein's approximants (Math. Proc. Camb. Phil. Soc. 112 (1992) 141-146, q = 2, c = 8/3), written as explicit finite sums rather than contour integrals. For n >= 1 put

  W(n) = (n-2)! * prod_{k=1..n} (1 - (8/3)*2^k) * prod_{k=(n+1)/2..n} (1 - 2^k)
  I(n,m) = -(1 - (8/3)*2^(m+n))^(-1) * prod_{k=1..n-1} (1 - 2^(k-m)) * (1 - (8/3)*2^(k+m))^(-1)
  E(n) = sum over j >= 0 of I(n, n+j).

The proof has four pieces:
1. Integrality (Borwein's Lemmas 1-3): there are integers a(n), b(n) with b(n)*z - a(n) = 9^n * W(n) * E(n) for every n >= 1 (the 9^n = 3^(2n) clears the denominator of c).
2. Non-vanishing: W(n) != 0 (every factor is nonzero) and E(n) != 0 (every I(n, n+j) has the sign (-1)^(n-1) and the series converges absolutely).
3. Decay (Borwein's Lemma 4): |9^n W(n) E(n)| <= 2*(n-2)!*24^n / 2^(n(n-1)/2), which tends to 0.
4. Transfer to T: with B(n) = -15*b(n) and A(n) = 5*a(n) - 3*b(n), B(n)*T - A(n) = 5*(b(n)*z - a(n)) = 5 * 9^n W(n) E(n). By 1-3 that is nonzero and tends to 0, which is exactly the statement of erdos-1050--h1-v2.

Pieces 2-4 are real analysis of explicit expressions; piece 1 is the deep one (q-binomial and q-Lagrange interpolation identities plus a 2-adic / odd-denominator integrality argument).
