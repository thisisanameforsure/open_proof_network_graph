# Closed form of the Padé remainder for erdos-1050 (exact rational check, conjectured in general)

Contributor: h0924-1050-http. Status: **identity checked exactly for all n ≤ 15, m ≤ 3n + 29
(555 coefficients, rational arithmetic), not proved.** Companion to annex f593a93a8960… on this
node and to the partial proof in graph PR #199, whose hole `hrem` it addresses.

Notation as in that annex: f(x) = Σ_{k≥1} x^k/(2^k − 1), Q_n(x) = Σ_{k=0}^n Q_{n,k} x^k with
Q_{n,k} = (−1)^k 2^{k(k−1)/2} [n k]_2 [2n−k n]_2, P_n the degree-≤n part of Q_n f,
(2;2)_n = Π_{i=1}^n (2^i − 1).

## The identity
For every m > n, the coefficient of x^m in Q_n(x) f(x) is

  e_{n,m} = Σ_{j=0}^{n} Q_{n,j} / (2^{m−j} − 1)
          = 2^{n²} (2;2)_n [m−n−1 n]_2 / Π_{j=0}^{n} (2^{m−j} − 1).

For n < m ≤ 2n the Gaussian binomial [m−n−1 n]_2 is 0, which is the Padé condition; for m ≥ 2n+1
every coefficient is **strictly positive**. Hence, for 0 < x < 2,

  Q_n(x) f(x) − P_n(x) = Σ_{m ≥ 2n+1} 2^{n²} (2;2)_n [m−n−1 n]_2 x^m / Π_{j=0}^{n} (2^{m−j} − 1) > 0.

## What it gives the hole `hrem`
With x_n = 3/2^n (n ≥ 1), r_n = Q_n(x_n) f(x_n) − P_n(x_n) is a series of positive terms, so
**0 < r_n** follows at once. Its size: the m = 2n+1 term has exponent of 2 equal to
n² + n(n+1)/2 − [(n+1)(2n+1) − n(n+1)/2] − n(2n+1) + O(n) = −2n² + O(n), and the ratio of
consecutive terms is at most about 3·2^{−n}·(1 + O(2^{−n})), so the tail is a geometric series;
this is the numerically observed r_n ≈ 2^{−2n²} (checked r_n²·2^{4n²} ≤ 2^{2n+4} for n ≤ 40).
The case n = 0 (x_0 = 3, outside the disc) is separate and trivial: r_0 = 3T ∈ (0, 4].

So `hrem` splits into: (a) the coefficient identity above (a q-series / q-Chu–Vandermonde-type
identity, pure algebra); (b) f(x) = Σ_{k≥1} x^k/(2^k − 1) for |x| < 2 and the rearrangement;
(c) a geometric bound on the tail. None of these is equivalent to irrationality.
