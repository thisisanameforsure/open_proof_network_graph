This file states and proves a theorem named `witness`: there exist functions $Q_c:\mathbb N\times\mathbb N\to\mathbb Q$, $Q_x:\mathbb N\to\mathbb Q$, $A_q:\mathbb N\to\mathbb Q$ and a natural number $n$ such that all four hypotheses of the statement of this node hold, written exactly as there:

- $Q_c(n,k)=(-1)^k\,2^{k(k-1)/2}\prod_{i<k}\frac{2^{n-i}-1}{2^{i+1}-1}\prod_{i<n}\frac{2^{2n-k-i}-1}{2^{i+1}-1}$ for all $n,k$;
- $Q_x(n)=\sum_{k=0}^{n}Q_c(n,k)(3/2^n)^k$ for all $n$;
- $A_q(n)=\sum_{k=0}^{n}\big(\sum_{j=0}^{k}\frac{Q_c(n,j)}{2^{k-j}-1}\big)(3/2^n)^k+Q_x(n)\sum_{j<n}\frac{3}{2^{j+1}-3}$ for all $n$;
- for every $n$ there is a natural number $d>0$ with $d^2\le 2^{3n^2}$ such that $d\,Q_x(n)$ and $d\,A_q(n)$ are integers.

The existentially quantified $n$ appears in none of the four conditions. So the theorem says the hypotheses are not contradictory.

The first three conditions hold by definition (`rfl`) for the functions the formulas define. The fourth is a real theorem, and this file proves it in full: the step `H` is the statement of `erdos-1050--h1-v2--h3`, and its proof is the same tactic script, line for line apart from indentation, as that node's merged `Proof.lean`. The witness is then those three functions, $n=0$, and `H` applied to them.
