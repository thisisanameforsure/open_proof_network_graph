$$\forall M\ \exists N\ge M:\ \operatorname{frac}\Big(\sum_{n=2}^{N}\frac{N!}{n!-1}\Big)<1-\frac{2}{N}$$

The open core. A finite statement about rationals with no analysis left in it, strictly stronger than the root: if S = p/q, the fractional part equals 1 - c with 0 < c ≤ 2/N for every N ≥ max(q, 2).
