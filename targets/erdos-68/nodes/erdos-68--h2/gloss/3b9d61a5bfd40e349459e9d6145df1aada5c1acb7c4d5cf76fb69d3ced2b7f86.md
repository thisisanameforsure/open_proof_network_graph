$$\forall N\ge 2\ \exists c,\ 0<c\le \tfrac{2}{N}\ \text{and}\ N!\sum_{n\ge 2}\frac{1}{n!-1}=\sum_{n=2}^{N}\frac{N!}{n!-1}+c$$

c = N!·Σ_{n>N} 1/(n!-1); since n!-1 ≥ n!/2, c ≤ 2·Σ_{j≥1} (N+1)^{-j} = 2/N. Elementary.
