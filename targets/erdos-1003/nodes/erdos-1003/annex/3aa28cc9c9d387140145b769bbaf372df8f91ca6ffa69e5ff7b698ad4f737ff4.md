Notes for Erdős 1003 (infinitely many n with phi(n) = phi(n+1)).
Small solutions: n = 1, 3, 15, 104, 164, 194, 255, 495, 584, 975 (OEIS A001274). A Lean-core decide check confirms phi(1)=phi(2) and phi(3)=phi(4) and phi(15)=phi(16).
No reduction to a known theorem is known: the problem is open (Erdős, Pomerance, Sárközy proved the count up to x is o(x), but infinitude is unproved; it would follow from Schinzel-type prime-pattern conjectures, e.g. n = 2p-1 style patterns need simultaneous primality of linear forms).
A skeleton of the form "for every N there is n >= N with phi n = phi (n+1)" would be a single hole equal to the goal, i.e. a rename, which D-12 rejects; so no skeleton is submitted.
