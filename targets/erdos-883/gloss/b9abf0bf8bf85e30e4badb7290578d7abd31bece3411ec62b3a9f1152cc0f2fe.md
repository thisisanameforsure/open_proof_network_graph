$$\operatorname{cycleLengths}(G)=\{m\in\mathbb N:\exists\,a\in V,\ \exists\text{ closed walk }w\text{ at }a,\ w\text{ is a cycle},\ |w|=m\},\qquad \operatorname{oddCycleLengths}(G)=\{m\in\operatorname{cycleLengths}(G): m\text{ odd}\},\qquad \operatorname{circumference}(G)=\sup\operatorname{cycleLengths}(G)$$

- A cycle is Mathlib's `Walk.IsCycle`: a nonempty closed walk with no repeated edge whose only repeated vertex is the start and end vertex. Every cycle therefore has length at least 3, and `cycleLengths G` never contains 0, 1 or 2.
- `length` counts edges, so a cycle of length $m$ has $m$ distinct vertices.
- `circumference` is the `sSup` of a set of natural numbers. It is $0$ when $G$ has no cycle, because `sSup ∅ = 0` on ℕ. On a finite vertex type the set is bounded, so the supremum is the largest cycle length. The `[Fintype α]` and `[DecidableRel G.Adj]` hypotheses only make that reading safe; nothing in the definition uses them.

This file names the set that Erdős 883 asks about. "$G(A)$ contains a cycle of length $l$" is written `l ∈ (coprimeGraph.induce A).oddCycleLengths` for odd $l$. A cycle of length $l$ can be built from a copy of Mathlib's `cycleGraph l` (for $l>2$) by `SimpleGraph.cycleGraph_isContained_iff`.
