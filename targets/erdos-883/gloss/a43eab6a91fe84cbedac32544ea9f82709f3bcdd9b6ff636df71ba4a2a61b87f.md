$$e(x) \;=\; \exp(2\pi i x) \in \mathbb{C}, \qquad x \in \mathbb{R}.$$

`additiveChar x` is the complex number $\exp\big((2\pi x)\, i\big)$ for a real number $x$. In the Lean, the product $2\pi x$ is formed in $\mathbb{R}$ and then cast to $\mathbb{C}$ before multiplying by `Complex.I`, so the input is always real; there is no version for complex arguments here. The definition is `noncomputable` because `Complex.exp` is.

The file also introduces the scoped notation `e` for `additiveChar`, available only after `open ExponentialSum` (or `open scoped ExponentialSum`). The name is the standard shorthand from analytic number theory for exponential sums: $e(x)$ has absolute value $1$, is $1$-periodic ($e(x+1)=e(x)$), and turns sums into products ($e(x+y)=e(x)e(y)$); these facts are not stated in this file and must be taken from Mathlib's `Complex.exp` lemmas.
