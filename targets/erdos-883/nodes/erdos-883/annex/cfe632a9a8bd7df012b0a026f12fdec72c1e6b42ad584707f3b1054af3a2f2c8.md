# Erdős 883 (i): statement review, finite check, and a split at l = 3

## 1. The Lean says what the problem says

- `n / 2 + n / 3 - n / 6` is $\lfloor n/2\rfloor+\lfloor n/3\rfloor-\lfloor n/6\rfloor$. ℕ-subtraction cannot truncate because $\lfloor n/6\rfloor\le\lfloor n/2\rfloor$.
- `l ≤ n / 3 + 1` with `l : ℕ` is equivalent to the real inequality $l\le n/3+1$, because $l\le x+1 \iff l\le\lfloor x\rfloor+1$ for integer $l$.
- `Odd l → 3 ≤ l` ranges over all odd cycle lengths, since cycles have length at least 3.
- `coprimeGraph = SimpleGraph.fromRel Nat.Coprime`: distinct $a,b$ adjacent iff $\gcd(a,b)=1$, induced on $A$. `oddCycleLengths` uses Mathlib's `Walk.IsCycle`.

I found no defect to file.

## 2. Finite check

An exhaustive search over every $A\subseteq\{1,\dots,n\}$ with $|A| = T(n)+1$, where $T(n)=\lfloor n/2\rfloor+\lfloor n/3\rfloor-\lfloor n/6\rfloor$, found a simple cycle of every odd length $3\le l\le\lfloor n/3\rfloor+1$ for each $n\le 22$. Supersets inherit the cycles, so the statement holds for all $n\le 22$. No counterexample appears in small cases.

## 3. Sharpness

$A=\{m\le n: 2\mid m \text{ or } 3\mid m\}$ has exactly $T(n)$ elements. Among any three of its elements, two are even or two are multiples of 3, so it has no triangle. The bound is therefore sharp already at $l=3$.

## 4. The split used by the partial

1. **h_tri (l = 3).** If $|A|>T(n)$, then $A$ has three distinct pairwise coprime elements. This is the $k=3$ case of Erdős's question on the largest subset of $[n]$ with no $k$ pairwise coprime integers, which the extremal set above meets. Turning such a triple into a 3-cycle of `coprimeGraph.induce A` is proved in the partial (`erdos883_tri_mem`).
2. **h_long (odd l ≥ 5, l ≤ ⌊n/3⌋+1).** This hole is the core of Erdős–Sárközy, Electron. J. Combin. 1997. It is vacuous for $n<12$.

The assembly (an odd $l\ge 3$ is either $3$ or at least $5$) is checked in Lean.

## 5. Notes for whoever takes h_tri

A blocking argument over $\{6k+1,\dots,6k+6\}$ shows that at least 5 elements of $A$ in one block force a triangle: $\{6k+1,6k+2,6k+3\}$ and $\{6k+3,6k+4,6k+5\}$ are pairwise coprime triples, and so is $\{6k+1,6k+2,6k+5\}$. This alone does not finish the proof. With a remainder $n\bmod 6=1$, $A$ can take 4 elements per block plus $6q+1$, so a cross-block argument is needed.
