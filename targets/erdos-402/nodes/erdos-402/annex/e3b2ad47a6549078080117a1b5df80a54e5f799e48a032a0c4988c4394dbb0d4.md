A uniform finite method for the card-n variants, and how far it reaches.

Reduction. Let A have n elements, 0 not in A, and M = max A. If some x in A has n * gcd(M, x) <= M, the pair (M, x) works. Otherwise, for each other x write M = g*k and x = g*j with g = gcd(M, x); then 1 <= j < k < n, so x = (j/k) * M. With L = lcm(2, ..., n-1), every other element satisfies L * x = a * M for some a in F_n = { L*j/k : 1 <= j < k < n }. The map x -> a is injective, and for two such elements x, y with images a, b one has gcd(x, y) * L = gcd(a, b) * M (from gcd(Lx, Ly) = L gcd(x, y) and gcd(aM, bM) = gcd(a, b) M). Hence n * gcd(x, y) <= x exactly when n * gcd(a, b) <= a. Call a, b in F_n "bad" when n * gcd(a, b) <= max(a, b).

Finite core. It suffices that F_n has no n-1 pairwise non-bad elements. A convenient certificate is a partition of F_n into n-2 classes in which every two elements are bad (a clique cover of the bad graph): n-1 elements then put two in one class (pigeonhole), and that pair is the answer.

Lean. The proofs submitted for card_six, card_seven, card_eight (and proposed card_nine, card_ten) are one template: the reduction above, then Finset.exists_ne_map_eq_of_card_lt_of_maps_to with the colouring given as an explicit if-chain, and two decide facts over F_n (colours are < n-2; two distinct values of equal colour are bad). Every proof passed POST /check (AXLE, lean-4.33.1, exact pin) in about two seconds; card_six, seven and eight passed the service precheck.

Data (computed outside Lean with a SAT solver, NOT machine-checked in Lean beyond n <= 10): a clique cover of the bad graph on F_n by n-2 classes exists for every n from 6 to 16, and F_n has no n-1 pairwise non-bad elements for those n. |F_n| = 9, 11, 17, 21, 27, 31, 41, 45, 57, 63, 71 for n = 6..16. For n = 8 the classes are, as fractions of M: {1/7, 2/5, 3/4, 5/6}, {1/6, 2/7, 3/5}, {1/5, 3/7, 2/3}, {1/4, 4/7}, {1/3, 5/7, 4/5}, {1/2, 6/7}: one class per unit fraction 1/c, c = 2..7. Whether such an n-2 cover exists for every n is open as far as this note knows; if it did, it would give an elementary proof of the root (Graham's gcd problem, proved in general by Balasubramanian and Soundararajan, 1996). The finite core for fixed n is a Graham-type statement restricted to M * F_n, so the method cannot be easier than the conjecture for the sets it covers; it only shows that small n are routine.
