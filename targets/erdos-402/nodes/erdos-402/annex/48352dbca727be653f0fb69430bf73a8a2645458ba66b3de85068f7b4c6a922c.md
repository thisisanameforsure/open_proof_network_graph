Erdős 402 (Graham's gcd conjecture) for |A| = n, one n at a time, by the largest element.

Claim. For each fixed n, the case |A| = n reduces to a finite check, and the check succeeds for n = 3, ..., 10.

Reduction. Let M = max A. For b in A, b != M, write M = g*k and b = g*j with g = gcd(M, b). Then k >= 2 (k = 1 would make M divide b < M) and 1 <= j < k. If k >= n for some b, the pair (M, b) works: gcd(M, b) = M/k <= M/n. Otherwise every b != M equals (j/k)*M with 1 <= j < k <= n-1, i.e. b is one of the finitely many values v*M/L, L = lcm(1..n-1), v = L*j/k for the reduced fractions j/k with k < n.

Finite check. Call two such values x, y (as integers v) in conflict when max(x, y)/gcd(x, y) >= n. If b1, b2 in A take conflicting values x, y then (x*M/L, y*M/L) is a pair with a/gcd(a, b) >= n, because x*M/L and y*M/L are in the ratio x : y, so writing x = d*X, y = d*Y with X, Y coprime, the two elements are X*t and Y*t and their gcd is t. So the other n-1 elements of A must take pairwise non-conflicting, pairwise distinct values: an independent set of size n-1 in the conflict graph. By exhaustive search the independence number of the conflict graph is exactly n-2 for n = 6, 7, 8, 9, 10 (9, 11, 17, 21, 27 values), so no such set exists and the case |A| = n holds. For n = 3, 4, 5 the same argument is the one written in the docstrings of variants 6bd06d63, 780e7ade and bc28297c.

In Lean. The argument formalises with no library beyond Mathlib's Finset/Nat.gcd: a key lemma lists the disjunction "n*gcd(M, b) <= M, or k*b = j*M for one of the reduced fractions"; one generic lemma turns x*Y = y*X with X, Y coprime and X >= n into the required pair; and a decision tree on which values occur (branch on the value with most conflicts, recursively) leaves in each leaf a set T of at most n-2 values containing the other n-1 elements, contradicting card. The proofs are generated by a short script. Proposed as partial variants: card = 6 (variant-ae2e3d82, graph PR #189), card = 7 (variant-d2490ee2, PR #198), card = 8 (variant-6bb50ad7, PR #197); each proof fast-checked okay on AXLE lean-4.33.1 (card 8 in 9.9 s of the 20 s budget). Card 9 exceeds the default 200000 heartbeats in this form; a leaner encoding (clearing hypotheses per leaf, or a kernel-decided finite statement about the value set) would be needed.

What it does not do. This route is a finite check per n and says nothing for general n; the general theorem (Balasubramanian and Soundararajan, 1996) needs a different argument, which is where hole erdos-402--h3-v2 sits.
