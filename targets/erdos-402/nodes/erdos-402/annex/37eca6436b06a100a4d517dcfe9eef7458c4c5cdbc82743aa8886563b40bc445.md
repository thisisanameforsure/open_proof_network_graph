Erdős 402 (Graham's gcd conjecture) when some element has no small prime factor.

Claim. Let A be a finite set of positive integers, n = |A|, and suppose some x in A has minFac(x) >= n. Then there are a, b in A with gcd(a, b) <= a / n.

Proof. Two cases.
(1) x divides every element of A. Map b -> b / x: it is injective on A and lands in [1, m/x] where m = max A, so n <= m/x, i.e. n*x <= m. Take a = m, b = x: gcd(m, x) = x <= m / n.
(2) Some b in A is not a multiple of x. Write x = gcd(x, b) * k. k != 0 (x > 0) and k != 1 (else x | b), so k >= 2 and k | x, hence k >= minFac(x) >= n. Take a = x: gcd(x, b) * n <= gcd(x, b) * k = x.

The case of a prime p >= n in A is the special case minFac(p) = p.

/-! Graham's gcd conjecture (Erdős problem 402) when some element `x` of `A` has no prime factor
below `|A|`: either `x` divides every element, and then the largest element is at least `|A| * x`,
or `gcd(x, b) < x` for some `b`, and then `x / gcd(x, b)` is a divisor of `x` above 1, so at
least `x.minFac ≥ |A|`. Contains the case of a prime `p ≥ |A|` in `A`. -/

theorem Opn.erdos_402_minFac :
    ∀ (A : Finset ℕ), 0 ∉ A → ∀ x ∈ A, A.card ≤ x.minFac →
      ∃ a ∈ A, ∃ b ∈ A, a.gcd b ≤ (a / A.card : ℚ) := by
  intro A hA x hx hmin
  have hx0 : x ≠ 0 := fun h => hA (h ▸ hx)
  have hn : 0 < A.card := Finset.card_pos.mpr ⟨x, hx⟩
  have hnq : (0 : ℚ) < A.card := by exact_mod_cast hn
  by_cases hall : ∀ b ∈ A, x ∣ b
  · set m := A.max' ⟨x, hx⟩ with hm
    have hmA : m ∈ A := A.max'_mem _
    have hle : A.card ≤ m / x := by
      have : A.card ≤ (Finset.Icc 1 (m / x)).card := by
        apply Finset.card_le_card_of_injOn (fun b => b / x)
        · intro b hb
          have hbx := hall b hb
          have hb0 : b ≠ 0 := fun h => hA (h ▸ hb)
          have hbm : b ≤ m := A.le_max' b hb
          simp only [Finset.coe_Icc, Set.mem_Icc]
          constructor
          · exact Nat.div_pos (Nat.le_of_dvd (Nat.pos_of_ne_zero hb0) hbx) (Nat.pos_of_ne_zero hx0)
          · exact Nat.div_le_div_right hbm
        · intro b hb c hc hbc
          have e1 := Nat.div_mul_cancel (hall b hb)
          have e2 := Nat.div_mul_cancel (hall c hc)
          simp only at hbc
          rw [← e1, ← e2, hbc]
      simpa using this
    have hxm : x ∣ m := hall m hmA
    refine ⟨m, hmA, x, hx, ?_⟩
    have hg : m.gcd x = x := Nat.gcd_eq_right hxm
    rw [hg, le_div_iff₀ hnq]
    have h1 : A.card * x ≤ m := by
      have := Nat.mul_le_mul_right x hle
      calc A.card * x ≤ m / x * x := this
        _ ≤ m := Nat.div_mul_le_self m x
    have : ((A.card * x : ℕ) : ℚ) ≤ m := by exact_mod_cast h1
    push_cast at this
    linarith
  · push_neg at hall
    obtain ⟨b, hb, hxb⟩ := hall
    refine ⟨x, hx, b, hb, ?_⟩
    obtain ⟨k, hk⟩ := Nat.gcd_dvd_left x b
    have hk0 : k ≠ 0 := by
      rintro rfl; exact hx0 (by simpa using hk)
    have hk1 : k ≠ 1 := by
      rintro rfl
      apply hxb
      have : x = x.gcd b := by simpa using hk
      rw [this]; exact Nat.gcd_dvd_right x b
    have hk2 : 2 ≤ k := by omega
    have hkx : k ∣ x := Dvd.intro_left _ hk.symm
    have hmk : x.minFac ≤ k := Nat.minFac_le_of_dvd hk2 hkx
    have h1 : x.gcd b * A.card ≤ x := by
      calc x.gcd b * A.card ≤ x.gcd b * k := Nat.mul_le_mul_left _ (hmin.trans hmk)
        _ = x := hk.symm
    rw [le_div_iff₀ hnq]
    exact_mod_cast h1
