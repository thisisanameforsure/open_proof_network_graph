Small cases of Graham's gcd problem by a finite check at the largest element (informal; machine-checked for |A| = 3, 4, 5, 6, 7)

Let n = |A| and M = max A. It is enough to find b in A with M / gcd(M, b) ≥ n, or else some other pair (a, b) with a / gcd(a, b) ≥ n.

1. Write g = gcd(M, b) for b ≠ M in A, with M = k g and b = j g. Since b < M we have 1 ≤ j < k. If k ≥ n the pair (M, b) works. Otherwise b = (j/k) M with k < n, so every element other than M is one of the finitely many values (j/k) M with 1 ≤ j < k < n.

2. Put all these values over the common denominator L = lcm(2, …, n−1), so the value (j/k) M is (jL/k)·(M/L). A pair of them (u, v) works when u / gcd(u, v) ≥ n, and this depends only on the integers jL/k, not on M: gcd(u, v) divides c v − d u for any naturals c, d, and choosing c, d from Bezout on the two integers gives gcd(u, v) ≤ gcd(jL/k, j'L/k')·(M/L).

3. So the case |A| = n follows once every (n−1)-element set of the values jL/k contains a working pair. A search shows the largest set with no working pair has size n − 2 for n = 3, …, 10 (e.g. {M/5, 2M/5, 3M/5, 4M/5} for n = 6), so the method proves each of those cases. The Lean proofs for n = 3, 4, 5 (variants card_three/four/five) and the proposed card_six and card_seven are generated case trees: by_cases on which values are present; a present working pair closes by the Bezout bound and omega; otherwise A minus M lies in a set of at most n − 2 values, contradicting the cardinality.

4. The method does not scale to the root: the number of values grows like n², and whether every (n−1)-subset contains a working pair is exactly the content of the conjecture for sets containing their own maximum, i.e. all of it. The general statement (Graham's conjecture) was settled by Balasubramanian and Soundararajan (1996) with analytic methods; hole h3-v2 of the skeleton carries that whole difficulty (gcd(A) = 1 and all reduced ratios with numerator and denominator at most n force a ratio with numerator exactly n), and is not elementary.

Also: when A contains x with minFac x ≥ |A| (variant minFac, which contains variant large_prime), the pair (x, b) works for any b with gcd(x, b) < x, because x / gcd(x, b) is then a divisor of x above 1; and if x divides everything, A ⊆ x·[1, M/x] gives |A| ≤ M/x and the pair (M, x) works.
