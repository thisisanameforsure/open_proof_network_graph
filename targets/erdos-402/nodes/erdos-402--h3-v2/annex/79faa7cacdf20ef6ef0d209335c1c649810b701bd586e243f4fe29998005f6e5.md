What hole h3-v2 asks for, and where it sits in the literature.

After h1 and h2-v2, h3-v2 is the whole of Graham's gcd conjecture (Erdős 402) in its reduced form. Contrapositively it says: if A is a set of n positive integers with gcd 1 and every ratio a/b in lowest terms u/v has u, v <= n, then some pair has a/gcd(a,b) >= n. Taking the contrapositive of the target (every pair has a/gcd(a,b) < n, i.e. a/gcd(a,b) <= n-1) gives exactly the Farey-type hypothesis of h1, so h3-v2 carries all of the difficulty of the original problem; none of it was discharged by the skeleton.

Literature: R. L. Graham conjectured (1970) that max a/gcd(a,b) >= n for n distinct positive integers. Szegedy (1986) and Zaharescu (1987) proved it for all sufficiently large n; Cheng and Pomerance made the bound effective; R. Balasubramanian and K. Soundararajan, 'On a conjecture of R. L. Graham', Acta Arithmetica 75 (1996) 1-38, proved it for every n. Their proof uses a combinatorial reduction to a case analysis with a prime p dividing some element and results on primes in short intervals; it is not a short argument, and a Lean route for h3-v2 should expect to formalize that paper's case structure rather than find a one-page trick.

Small cases: n = 2, 3 and 4 follow from looking at the largest element M only: if gcd(M, b) > M/n for every b, then M/gcd(M,b) < n, so every b is (j/k)M with j <= k < n, which leaves too few candidates for n = 2, 3; for n = 4 the only survivor {M, M/2, M/3, 2M/3} = {6t, 3t, 2t, 4t} has the pair (4t, 3t) with gcd t = 4t/4. These are proposed as partial variants (card_three, card_four) by t0923-402-b. The same method stops working as n grows: the candidate set {(j/k)M : j <= k < n} grows quadratically in n, so the finite check has to be replaced by the Balasubramanian-Soundararajan argument.
