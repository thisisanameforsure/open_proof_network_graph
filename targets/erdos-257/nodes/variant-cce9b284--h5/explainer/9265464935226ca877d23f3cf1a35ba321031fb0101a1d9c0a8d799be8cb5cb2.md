## Statement

Write $t_k = \frac{1}{2^k-1}$. For the greedy walk $r$ of $2^{-20}$ (index $k \ge 1$ is taken when $t_k \le r_k$, and then $r_{k+1} = r_k - t_k$), no step $j = n+1$ with $n \le 1091$ is a stall: it is never the case that $r_j < t_j$ and $\sum_{i \ge 0} t_{j+1+i} < r_j$.

## Interval arithmetic in integers (`opnLoop`)

Fix $D = 2^{1300}$ and carry natural numbers $lo \le D r_k \le hi$, starting at $k = 1$ with $lo = hi = 2^{1280} = D \cdot 2^{-20}$ (index $0$ is never taken, so $r_1 = r_0$). At each step the program either certifies a decision and updates the interval, or returns `false`:

- **Taken.** If $D \le lo\,(2^k - 1)$, then $t_k \le r_k$. With $q = \lfloor D/(2^k-1) \rfloor$ we have $q \le D t_k < q + 1$, so $D r_{k+1} \in [lo - q - 1,\ hi - q]$ (the program checks that $lo \ge q+1$ and $hi \ge q$).
- **Skipped, and not a stall.** Otherwise it checks $hi\,(2^k - 1) < D$, which gives $r_k < t_k$ (skipped, so the interval is unchanged), and $hi \cdot 3 \cdot 4^k \le D(3 \cdot 2^k + 1)$, which gives $r_k \le \frac{3 \cdot 2^k + 1}{3 \cdot 4^k}$.

## The tail bound (`opn_term_lb`, `opn_tail_lb`)

Since $t_j \ge 2^{-j} + 4^{-j}$, $\sum_{i\ge0} t_{k+1+i} \ge 2^{-k} + \frac{4^{-k}}{3} = \frac{3\cdot 2^k + 1}{3 \cdot 4^k}$. So in the skipped branch $r_k$ is at most the tail, and step $k$ is not a stall.

## Soundness and the kernel run (`opn_sound`, `opnLoop_true`)

By induction on the number of steps, if `opnLoop` returns `true` from an interval containing $D r_k$, then no $j \in [k, k+f)$ is a stall; the real-number facts above are each step. The kernel evaluates `opnLoop (2^1300) 1092 1 (2^1280) (2^1280) = true` by `decide +kernel`. That covers $j = 1, \dots, 1092$, which are the steps $n + 1$ for $n \le 1091$. $\blacksquare$

The 20 extra bits of $D$ beyond the start absorb the rounding loss of at most one unit per taken step.
