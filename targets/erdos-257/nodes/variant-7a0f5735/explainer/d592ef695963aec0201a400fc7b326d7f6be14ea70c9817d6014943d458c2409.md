## Overview

Fix $k \ge 1$. Erdős's 1948 argument for $A = \mathbb{N}$, run with the divisor count replaced by $f_k(N) = \#\{e \mid N : e^k \mid N\}$ (with $f_k(0) = 0$). The theorem, for each $k \ge 1$, rewrites the sum with `series_eq_fk` and applies `irrational_fk_series`; everything else is in private helper declarations.

**The Lambert series.** `series_eq_fk`: $\sum_{m \in \{n^k\}} \frac{1}{2^m - 1} = \sum_{N \ge 0} \frac{f_k(N)}{2^N}$. The sum over the set is re-indexed by $n$ (as $n \mapsto n^k$ is injective), the $n = 0$ term ($\frac10 = 0$ in Lean) is dropped, each $\frac{1}{2^{(n+1)^k} - 1}$ is expanded as $\sum_{j \ge 0} 2^{-(j+1)(n+1)^k}$, and the double sum is moved along the injective map $(n, j) \mapsto \bigl((j+1)(n+1)^k,\ n+1\bigr)$ (`phiK`) and summed over each fibre (`tsum_Ht_fiber`): the terms with first coordinate $N$ are the $e = n+1$ with $e^k \mid N$, which number $f_k(N)$.

**Forced divisibility.** Let $r_k(N) = \prod_p p^{\lfloor v_p(N)/k \rfloor}$ (`rk`). For $N \ne 0$, $e^k \mid N$ exactly when $e \mid r_k(N)$ (`pow_dvd_iff_dvd_rk`), so $f_k(N) = d(r_k(N))$ (`fk_eq_dd_rk`). A prime $p$ with $p^k \parallel N$ divides $r_k(N)$ exactly once, so if $m$ distinct primes each satisfy $p^k \parallel N$, then $2^m \mid f_k(N)$ (`pow_two_dvd_fk`, through `pow_two_dvd_dd`).

**Tails, the construction and the contradiction.** As for $A = \mathbb{N}$ with $f_k$ in place of $d$: if $\sum_N f_k(N)/2^N = a/b$, every scaled tail $T_j = b\sum_{i \ge 1} f_k(j+i)/2^i$ is a positive integer (`tail_eq_Zint`, `tail_pos`), and $2^m \mid f_k(n)$ for $s < n \le s+m$ forces $T_{s+m} \ge 2^m$ (`Zint_dvd`). Choose $m \ge b$, $m \ge k$ with $15m^6 < 2^m$ (`exists_param`), Bertrand primes $p_{ij}$, $i, j < m$, all above $2^m$, and by the Chinese remainder theorem $c$ modulo $Q = \prod p_{ij}^{k+1}$ with $c + i + 1 \equiv p_{ij}^{k+1} + p_{ij}^k \pmod{p_{ij}^{k+1}}$, so that $p_{ij}^k \parallel c + tQ + i + 1$ for every $t$. Then $T_{c+tQ+m} \ge 2^m$ for every $t$. Since $f_k \le d$ (`fk_le_dd`), the divisor-function average along a progression coprime to $Q$ applies (`sum_fk_AP_le`), $f_k(n) \le n$ bounds the far tail (`tail_upper`), and summing over $t$ contradicts the choice of $m$, now with $q = (k+1)(m + m^2)m^2$ (`averaging_contra`, `param_facts`).
