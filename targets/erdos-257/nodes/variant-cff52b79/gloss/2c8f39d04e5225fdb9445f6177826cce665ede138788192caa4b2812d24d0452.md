$$\Bigl(\forall\, A \subseteq \mathbb{N}\ \text{infinite}:\ \sum_{n\in A}\frac{1}{2^n-1}\notin\mathbb{Q}\Bigr) \;\Longrightarrow\; \Bigl(\forall\, A \subseteq \mathbb{N}:\ \sum_{n\in A}\frac{1}{2^n-1}\notin\mathbb{Q}\ \ \text{or}\ \sum_{n\in \mathbb{N}\setminus A}\frac{1}{2^n-1}\notin\mathbb{Q}\Bigr).$$

The hypothesis is the root statement; the conclusion is this node's statement. So the file proves that the root implies this node.

The Lean takes a set $A$ and splits on whether $A$ is finite. If $A$ is finite, its complement is infinite, and the root applied to the complement gives the second alternative. If $A$ is not finite, the root applied to $A$ itself gives the first alternative.
