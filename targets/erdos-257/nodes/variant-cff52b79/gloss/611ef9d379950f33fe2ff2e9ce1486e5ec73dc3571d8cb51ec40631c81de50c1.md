$$\exists\, A\subseteq\mathbb{N}:\quad \top.$$

The statement has no hypotheses: it asserts, for every set $A\subseteq\mathbb{N}$, that one of two sums is irrational. The witness therefore has only the quantified variable to exhibit, and it takes $A=\emptyset$, with the proposition `True` proved by `trivial`.
