# The affirmative side by denominators: what Liouville's argument proves for Erdős 257, and where it stops

Written by agent B of the 2026-10-22 run. The three theorems in §2 are proved in Lean (fast-checked; proposed as partial variants of the root, proofs prechecked and waiting for their proposals to merge). §3 is an informal argument that has not been formalized.

Write $t_n = 1/(2^n-1)$ and $S(A) = \sum_{n\in A} t_n$ for a set $A$ of positive integers.

## 1. The one inequality

Suppose $S(A) = p/q$ and let $m\in A$. Let $L$ be any common multiple of the numbers $2^a-1$ over the elements $a<m$ of $A$. Then $L\sum_{a\in A,\,a<m} t_a$ is an integer, so $qL\,T_m$ is a **positive integer**, where $T_m = \sum_{n\in A,\,n\ge m} t_n$ is the tail. The tail is positive (it contains $t_m$) and $T_m \le \sum_{n\ge m} 2^{1-n} = 4\cdot 2^{-m}$. Hence

$$2^m < 4qL \qquad\text{for every } m\in A.$$

Every result below is this inequality violated for some $m$.

## 2. What it proves (Lean)

* **Liouville's criterion** (`Opn.erdos_257_liouville_criterion`, node `variant-1629563f`): if for every $C$ some $m\in A$ admits such an $L$ with $2^C L\le 2^m$, then $S(A)$ is irrational.
* **Eventually lacunary of ratio two** (`Opn.erdos_257_eventually_ratio_two`, node `variant-d144ccc1`): if from some point on any two elements $n<m$ of $A$ satisfy $m\ge 2n$, then $S(A)$ is irrational. Examples: $\{2^k\}$, $\{2^k-1\}$, $\{3^k\}$, $\{k!\}$, every infinite divisibility chain, and finite modifications. Two cases. If infinitely many $a\in A$ have $2a\notin A$, then the elements below $m$ sum to at most $m$ minus the number of such $a$ below $m$ (induction on the largest element), and $L = \prod(2^a-1)$ works. If only finitely many do, the set is eventually a doubling chain $n, 2n, 4n,\dots$; every element from the last exception up to $n$ divides $n$, and $L = \prod_{a\text{ small}}(2^a-1)\cdot(2^n-1)$ with $m = 2n$ works.
* **Long gaps** (`Opn.erdos_257_long_gaps`, node `variant-41d1f19b`): if for every $C$ some $m\in A$ exceeds the sum of the elements of $A$ below it by at least $C$, then $S(A)$ is irrational. This allows long dense blocks, so $\sum_{a\in A}1/a$ may diverge: $A = \bigcup_j [X_j, 2X_j]$ with $X_{j+1} = 4X_j^2$. Erdős (1968) needs summable reciprocals, so these sets are outside his theorem.

## 3. One more case, not formalized: $A = \{2^k\}\cup\{3^k\}$

Neither part alone fails, but the union is not lacunary of ratio two. Each part is a divisibility chain, so below $m$ the common denominator is $L = (2^{3^J}-1)(2^{2^K}-1)$ with $3^J$, $2^K$ the largest powers below $m$. At $m = 3^{J+1}$ the criterion needs $2^K \le 2\cdot 3^J - C$. Put $u_J = 2^{K}/3^J\in[3/2,3)$, where $2^K$ is the largest power of two below $3^{J+1}$. Then $\log_2 u_J$ moves by the irrational rotation $\log_2 3$ and enters the good arc $u\in[3/2,2)$ at least once in every three steps. The margin $2\cdot 3^{J+1} - 2^{K'}$ at a hit can stay below $C$ for ever only if two such near-equalities occur a bounded number of steps apart. Dividing one by the other then gives $2^a\approx 3^b$, with bounded $a, b$, to exponentially small relative error, which is impossible. So the union is irrational by this elementary route. The Lean needs the rotation bookkeeping and is left open.

## 4. Where it stops

The route never uses the greedy structure, only the size of the common denominator, and it fails for every set that is not very sparse:

* For lacunary ratio $\lambda<2$, the earlier elements sum to about $\lambda m/(\lambda-1) > m$, so the product bound fails. Only arithmetic coincidences can save it, as for chains or for the union in §3.
* For a set of positive density, the lcm of the $2^a-1$ below $m$ contains the cyclotomic factors $\Phi_d(2)\approx 2^{\varphi(d)}$ for every $d$ in the set. Its logarithm is of order $m^2$, so $2^m<4qL$ holds trivially.

The open core `erdos-257--h2` is about greedy sets of rationals that never stall, and these look dense: the set for $1/2$ takes about half of all integers. So this route cannot touch the open core. That needs an argument about the digits of the sum, as in Erdős 1948 ($A=\mathbb N$, by the Chinese remainder theorem) or Tao–Teräväinen (the primes). A postmortem on `erdos-257--h2` (route class `direct-estimate`) records the same conclusion.
