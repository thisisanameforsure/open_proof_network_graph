## Statement

Write $t_k = \frac{1}{2^k-1}$ (Lean's $t_0 = 1/0 = 0$) and $T_n = \sum_{k \ge n+2} t_k$. Let $0 \le x \le 1$ and let $r$ be the greedy walk of $x$: $r_0 = x$, $r_{k+1} = r_k - t_k$ if $k \ge 1$ and $t_k \le r_k$ (index $k$ is *chosen*), else $r_{k+1} = r_k$. Suppose the walk never *stalls*: there is no $n$ with $r_{n+1} < t_{n+1}$ and $T_n < r_{n+1}$. Then $\sum_{a \text{ chosen}} t_a = x$.

## Tail bounds

$t_k \le 2 \cdot 2^{-k}$ (`opn_term_le`), so the $t_k$ are summable, $T_n = t_{n+2} + T_{n+1}$ (`opn_tail_succ`), and $T_n \le \sum_{i\ge0} 2 \cdot 2^{-(n+2+i)} = 2^{-n}$ (`opn_tail_le`).

## The remainder stays nonnegative and below the tail

A chosen step subtracts $t_k \le r_k$, so $r_k \ge 0$ for all $k$. By induction, $r_{n+1} \le t_{n+1} + T_n$. For $n = 0$: index $0$ is never chosen, so $r_1 = x \le 1 = t_1 \le t_1 + T_0$. Step: if $n+1$ is chosen, $r_{n+2} = r_{n+1} - t_{n+1} \le T_n = t_{n+2} + T_{n+1}$; if it is skipped, then $r_{n+1} < t_{n+1}$, so no stall gives $r_{n+2} = r_{n+1} \le T_n = t_{n+2} + T_{n+1}$.

## The remainder tends to zero

Hence $0 \le r_{n+1} \le 2\cdot 2^{-(n+1)} + 2^{-n} = 2 \cdot 2^{-n}$, and $r_N \to 0$ by squeezing.

## Telescoping

Let $f(a) = t_a$ if $a$ is chosen and $0$ otherwise. Then $f(a) = r_a - r_{a+1}$, so $\sum_{a < N} f(a) = x - r_N \to x$. As $f \ge 0$, this gives `HasSum f x`. The sum over the subtype of chosen indices is the sum of the indicator, which is $f$, so it equals $x$. $\blacksquare$
