$$\Bigl(\forall\, A \subseteq \mathbb{N}\ \text{infinite}:\ \sum_{n\in A}\frac{1}{2^n-1}\notin\mathbb{Q}\Bigr) \;\Longrightarrow\; \Bigl(\forall\, r\ge 1,\ \ c_1,\dots,c_r:\mathbb{N}\to\mathbb{N},\ \ c_i(0)>0,\ \ (2r+1)^{r+1}\,c_i(j)\le c_i(j+1)\ \ (\forall i,j):\ \ \sum_{n\in\bigcup_i\{c_i(j)\,:\,j\in\mathbb{N}\}}\frac{1}{2^n-1}\notin\mathbb{Q}\Bigr).$$

The sum is over the set of values of the $r$ sequences, each value once. The hypothesis is the root statement; the conclusion is this node's statement. So the file proves that the root implies this node.

The Lean applies the root to $A=\bigcup_i\{c_i(j)\}$ and checks only that $A$ is infinite: it contains the values of the first sequence, which is injective because $(2r+1)^{r+1}\ge 2$, so $c_1(0)>0$ and $2c_1(j)\le c_1(j+1)$ give $c_1(j)>j$ by induction and then $c_1(j)<c_1(j+1)$. The other sequences are not used.
