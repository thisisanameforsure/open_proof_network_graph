## What the assembly shows

One half is the sum $\sum_{n\in A}\frac{1}{2^n-1}$ over an infinite set $A$ as soon as some infinite set keeps its integer carries for the target $\frac12$ between $0$ and a linear bound. For a set $A$ write $D(m)$ for the number of elements of $A$ dividing $m$ when $m>0$, and $D(0)=0$. For an integer $p$ and a natural number $q>0$ the *carry* at position $j$ is the integer

$$Z_j \;=\; p\,2^j-q\sum_{m=0}^{j}D(m)\,2^{\,j-m}.$$

The partial has three holes. As of 12 November 2026 the first two are proved on the graph and the third is open, so this node is not proved. The third hole is where the construction of the set lies: the partial names no set and gives no argument that one exists. (The node also carries an earlier partial, by the greedy walk; this one is independent of it.)

## Lambert identity {steps: h_lambert}

For every set $A$,

$$\sum_{n\in A}\frac{1}{2^n-1}=\sum_{m\ge 0}\frac{D(m)}{2^m}.$$

This restates a node already on the graph, which is proved.

## Carry criterion {steps: h_crit}

For every $A$, $p$ and $q>0$: if $Z_j\ge 0$ for every $j$, and there is an integer $C$ with $Z_j\le C\,(j+1)$ for every $j$, then

$$\sum_{m\ge0}\frac{D(m)}{2^m}=\frac pq .$$

This hole is proved on the graph.

## Carries for one half {steps: h_carry}

The open hole: there is an infinite set $A$ and an integer $C$ such that, for every $j$,

$$0\;\le\;2^j-2\sum_{m=0}^{j}D(m)\,2^{\,j-m}\;\le\;C\,(j+1).$$

These are the carries $Z_j$ for $p=1$, $q=2$.

## The assembly {steps: s4 hsum close}

Take the infinite set $A$ and the bound $C$ from the third hole. Its two inequalities are the hypotheses of the carry criterion with $p=1$ and $q=2$, so $\sum_{m}D(m)/2^m=\frac12$. By the Lambert identity the left side is $\sum_{n\in A}\frac{1}{2^n-1}$. So $A$ is infinite and its sum is $\frac12$.
