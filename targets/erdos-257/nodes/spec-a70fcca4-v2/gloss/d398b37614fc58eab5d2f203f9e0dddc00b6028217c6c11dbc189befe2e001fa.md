$$\Bigl(\exists\, A \subseteq \mathbb{N} \text{ infinite},\ \sum_{n\in A}\frac{1}{2^n-1} = \frac12\Bigr) \;\Longrightarrow\; \neg\Bigl(\forall\, A \subseteq \mathbb{N} \text{ infinite},\ \sum_{n\in A}\frac{1}{2^n-1} \notin \mathbb{Q}\Bigr).$$

This variant (`refutes`) implies the negation of the root erdos-257: an infinite set whose sum is $\frac12$ is an infinite set whose sum is rational. Sums are Lean's `tsum` over $A$; the term at $n = 0$ is Lean's $\frac10 = 0$, the same convention on both sides.
