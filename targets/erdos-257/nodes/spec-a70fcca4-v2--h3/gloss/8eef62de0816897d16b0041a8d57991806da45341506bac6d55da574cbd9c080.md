$$\exists A\ \text{infinite}:\ 0\le 2^j-2\sum_{m\le j}d_A(m)\,2^{j-m}\le C(j+1)\ \forall j$$

Some infinite set A has carries for the target 1/2 (p = 1, q = 2) that stay nonnegative and at most linear, where d_A(m) counts the elements of A dividing m.
