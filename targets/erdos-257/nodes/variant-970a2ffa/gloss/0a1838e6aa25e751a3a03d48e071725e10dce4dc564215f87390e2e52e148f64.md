$$\Bigl(\forall\, A \subseteq \mathbb{N} \text{ infinite}:\ \sum_{n\in A}\frac{1}{2^n-1} \text{ is irrational}\Bigr) \;\Longrightarrow\; \sum_{n \text{ squarefree}}\frac{1}{2^n-1} \text{ is irrational}.$$

The root's statement implies this variant (relation `partial`): every prime is squarefree, so the set of squarefree numbers contains the infinite set of primes and is infinite, and the root's statement applies to it.
