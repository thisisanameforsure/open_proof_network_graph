## Overview

Erdős's 1948 argument for $A = \mathbb{N}$, run with the divisor count $d(n)$ replaced by $f(n) = \#\{e \mid n : e \text{ squarefree}\}$ (with $f(0) = 0$). The theorem rewrites the sum with `series_eq` and applies `irrational_ff_series`; everything else is in private helper declarations.

**The Lambert series.** `series_eq`: $\sum_{n \text{ squarefree}} \frac{1}{2^n-1} = \sum_{n \ge 0} \frac{f(n)}{2^n}$. Each $\frac{1}{2^n - 1}$ with $n \ge 1$ is expanded as $\sum_{k \ge 1} 2^{-nk}$, the double sum over pairs $(n, k)$ of positive integers is regrouped by $N = nk$ (Mathlib's divisor-antidiagonal equivalence, with summability from `summable_prod_mul_pow`), and the coefficient of $2^{-N}$ is the number of squarefree divisors of $N$.

**Tails are integers and are positive.** If $\sum_n f(n)/2^n = a/b$ with $b \ge 1$, then for every $j$ the scaled tail $T_j = b \sum_{i \ge 1} f(j+i)/2^i$ equals the integer $2^j a - b\sum_{n \le j} f(n)\,2^{\,j-n}$ (`tail_eq_Zint`), and $T_j > 0$ because $f(j+1) \ge 1$ (`tail_pos`). If $2^m \mid f(n)$ for all $k < n \le k+m$, then $2^m \mid T_{k+m}$ (`Zint_dvd`), so $T_{k+m} \ge 2^m$.

**Forced divisibility.** `pow_two_dvd_ff`: by Mathlib's `Nat.sum_divisors_filter_squarefree`, $f(n) = 2^{\omega(n)}$ for $n \ne 0$, where $\omega(n)$ is the number of distinct prime factors; so if $m$ distinct primes divide $n$, then $2^m \mid f(n)$.

**The construction and the contradiction.** As for $A = \mathbb{N}$: choose $m \ge b$ with $15m^5 < 2^m$, take $m^2$ distinct Bertrand primes $p_{ij} \in (2^{e}, 2^{e+1}]$ with $e = m + im + j$, and by the Chinese remainder theorem a residue $c$ modulo $Q = \prod p_{ij}^2$ with $p_{ij} \parallel c + tQ + i + 1$ for every $t$ and all $i, j < m$. Then $2^m \mid f(n)$ for the $m$ numbers after $c + tQ$, so $T_{c+tQ+m} \ge 2^m$ for every $t$. Since $f \le d$ (`ff_le_dd`), the average of $f$ along a progression coprime to $Q$ obeys the divisor-function bound $\sum_{t<X} f(r + tQ) \le 2X(2 + \log X)$ (`sum_ff_AP_le` from `sum_dd_AP_le`), and $f(n) \le n$ bounds the far tail (`tail_upper`). Summing over $t < X$ gives $2^m \le 2b(3 + q) + 1$ with $q = 2(m+m^2)m^2$, which the choice of $m$ makes false (`averaging_contra`).
