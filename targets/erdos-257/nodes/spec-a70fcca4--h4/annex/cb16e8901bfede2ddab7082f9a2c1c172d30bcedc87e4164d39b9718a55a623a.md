Notes on the greedy walk for 1/2 (spec-a70fcca4--h4), written while decomposing it.

Notation. e_n = 1/(2^n - 1) for n >= 1, T_m = sum_{n >= m} e_n (the tail), r_m the greedy remainder: r_0 = 1/2, r_{m+1} = r_m - e_m if e_m <= r_m, else r_m. A = {m : e_m <= r_m}.

1. Where a stall can happen. If r_m <= T_m and m is taken, then r_{m+1} = r_m - e_m <= T_m - e_m = T_{m+1}. So the bound r_m <= T_m can only fail at a skipped step, and it fails at the skipped step m exactly when T_{m+1} < r_m < e_m. Expanding 1/(2^n - 1) = sum_j 2^{-nj} gives T_{m+1} = sum_{j >= 1} 2^{-mj}/(2^j - 1) = 2^-m + 4^-m/3 + 8^-m/7 + ..., against e_m = 2^-m + 4^-m + 8^-m + ...: a window of width about (2/3) 4^-m. Termwise 1/(2^n - 1) >= 2^-n + 4^-n gives T_{m+1} >= 2^-m + 4^-m/3, so it suffices that a skipped remainder never lies in (2^-m + 4^-m/3, e_m). This is the partial in graph PR #815, proved in Lean with that one hole.

2. Scaled form. With x_m = 2^m r_m: m is taken iff x_m >= 1 + e_m; then x_{m+1} = 2(x_m - 1 - e_m), else x_{m+1} = 2 x_m. The hole says: a skipped x_m is at most 1 + 2^-m/3. Exactly, x_m = I_m - Phi(m) with I_m an integer and Phi(m) = sum_{a in A, a < m} 2^{(m mod a)}/(2^a - 1) (checked with exact rationals for m < 300). So a stall needs Phi(m) to fall within about 2^-m below an integer: a shrinking-target condition on one orbit. The denominators lcm(2^a - 1) are far too large for any congruence obstruction, and no invariant keeping Phi(m) away from integers was found.

3. Runs. While the walk takes consecutive elements, the deficit d_n = T_n - r_n is constant (both sides lose e_n); m is taken iff d_m <= T_{m+1}. Consequence, provable in Lean: if m is skipped and r_m > 2^-m, then every n in (m, 2m] is taken, because sum_{k=m+1}^{2m} e_k <= (2^-m - 4^-m) + (2/3) 4^-m < 2^-m (from 1/(2^k - 1) <= 2^-k + 2 * 4^-k). So hole 1 follows from the purely combinatorial statement "after every skipped m >= 2 the walk skips again within (m, 2m]" (m = 1 is checked by hand: r_1 = 1/2). Numerically (fixed point with 4M+64 bits, M = 5000; agent F to depth 20000): every skipped m has r_m <= 2^-m, with equality only at m = 1; the longest run of consecutive taken elements up to 5000 is 13 (the lead reports 20 up to 10^6), against the run of length m needed at step m.

4. Heuristic. If the scaled remainder at a skipped step were equidistributed at scale 2^-m, the chance of a stall at step m would be about (2/3) 2^-m; summed over m > N this is about 2^-N. With the walk run to 10^8 without a stall, a stall is heuristically of probability about 2^{-10^8}, which is why Kovac expects 1/2 to be a subset sum; a proof would need a reason the orbit avoids a target shrinking like 4^-m, which is not available for any explicit orbit of this kind.
