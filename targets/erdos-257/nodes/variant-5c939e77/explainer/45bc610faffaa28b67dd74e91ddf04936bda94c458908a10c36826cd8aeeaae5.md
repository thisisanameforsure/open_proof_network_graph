## What is proved, and how

Write $S(A)=\sum_{n\in A}\frac{1}{2^n-1}$ for a set $A$ of natural numbers. The statement is that the family

$$\mathcal F=\bigl\{A\subseteq\mathbb N \;:\; 0\notin A,\ S(A)\in\mathbb Q\bigr\}$$

is countable. Finite sets are in the family, so this does not say which infinite sets have a rational sum, only that there are at most countably many sets in all.

The proof uses one result from outside the file, the node's declared dependency `Opn.erdos_257_subsum_injective`: if $0\notin A$, $0\notin B$ and $S(A)=S(B)$, then $A=B$. Given that, the argument is a single application of a general fact (`Set.MapsTo.countable_of_injOn`): if a map sends a set $\mathcal F$ into a countable set and is injective on $\mathcal F$, then $\mathcal F$ is countable. The map is $A\mapsto S(A)$ and the countable set is the image of $\mathbb Q$ in $\mathbb R$, which is countable because it is the range of a map from a countable type. Two things remain to check, and they are the two steps below.

## The map lands in the rationals {steps: s1}

Let $A\in\mathcal F$. By the definition of $\mathcal F$ there is a rational $q$ with $S(A)=q$, so $S(A)$ lies in the image of $\mathbb Q$ in $\mathbb R$. The condition $0\notin A$ is not used here.

## The map is injective on the family {steps: s2}

Let $A,B\in\mathcal F$ with $S(A)=S(B)$. Both satisfy $0\notin A$ and $0\notin B$, so the dependency named above applies and gives $A=B$. The rationality of the two sums is not used here.
