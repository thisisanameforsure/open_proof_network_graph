$$\forall\, x, y : \mathbb{N} \to \mathbb{N},\quad \Big(x_0, y_0 > 0,\ \ x_j \mid x_{j+1},\ y_j \mid y_{j+1},\ 3x_j \le x_{j+1},\ 3y_j \le y_{j+1}\ \text{for all } j\Big) \;\Longrightarrow\; \sum_{n \in \{x_j\} \cup \{y_j\}} \frac{1}{2^n - 1} \notin \mathbb{Q}.$$

The sum is over the set of values of the two sequences, each value counted once. Each sequence is a divisibility chain of positive integers growing at least threefold per step, so every element is at least $1$ and no term meets Lean's junk value at $n = 0$.
