$$\Bigl(\forall\, A \subseteq \mathbb{N}\ \text{infinite}:\ \sum_{n\in A}\frac{1}{2^n-1}\notin\mathbb{Q}\Bigr) \;\Longrightarrow\; \Bigl(\forall\, x,y:\mathbb{N}\to\mathbb{N},\ \ x_0>0,\ y_0>0,\ \ x_j\mid x_{j+1},\ \ y_j\mid y_{j+1},\ \ 3x_j\le x_{j+1},\ \ 3y_j\le y_{j+1}\ \ (\forall j):\ \ \sum_{n\in\{x_j\}\cup\{y_j\}}\frac{1}{2^n-1}\notin\mathbb{Q}\Bigr).$$

The sum is over the set of values of the two sequences, each value once. The hypothesis is the root statement; the conclusion is this node's statement. So the file proves that the root implies this node.

The Lean applies the root to $A=\{x_j\}\cup\{y_j\}$ and checks only that $A$ is infinite: it contains the values of $x$, and $x$ is injective because $x_0>0$ and $3x_j\le x_{j+1}$ give $x_j>j$ by induction and then $x_j<x_{j+1}$. The divisibility hypotheses and everything about $y$ are not used.
