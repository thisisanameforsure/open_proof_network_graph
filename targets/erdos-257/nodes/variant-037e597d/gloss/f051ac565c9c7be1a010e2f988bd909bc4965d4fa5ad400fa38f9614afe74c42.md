$$\Bigl(\forall\, A \subseteq \mathbb{N}\ \text{infinite}:\ \sum_{n\in A}\frac{1}{2^n-1}\notin\mathbb{Q}\Bigr) \;\Longrightarrow\; \sum_{n \in \{2^k : k\in\mathbb{N}\}\cup\{3^k : k\in\mathbb{N}\}}\frac{1}{2^n-1}\notin\mathbb{Q}.$$

The hypothesis is the root statement, word for word; the conclusion is this node's statement. So the file proves that the root implies this node: the node is the root for one particular set.

The Lean applies the root to $A=\{2^k\}\cup\{3^k\}$. The only thing to check is that this set is infinite: it contains the set of powers of two, which is the range of the injective map $k\mapsto 2^k$. Nothing about the sum itself is computed.
