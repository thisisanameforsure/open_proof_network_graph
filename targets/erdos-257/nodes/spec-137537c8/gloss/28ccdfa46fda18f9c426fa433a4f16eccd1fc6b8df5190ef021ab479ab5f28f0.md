$$\exists\, A\subseteq\mathbb{N}:\quad \top.$$

The statement has no hypotheses: it is an identity asserted for every set $A\subseteq\mathbb{N}$. The witness therefore has only the quantified variable to exhibit, and it takes $A=\emptyset$, with the proposition `True` proved by `trivial`.
