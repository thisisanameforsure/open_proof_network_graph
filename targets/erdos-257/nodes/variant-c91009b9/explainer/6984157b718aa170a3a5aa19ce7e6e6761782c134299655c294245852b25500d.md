## Overview

Erdős's 1968 argument, without the Lambert series. For $a \ge 1$ and $n \ge 0$ put
$$w(a, n) = \frac{2^{\,n \bmod a}}{2^a - 1} = \sum_{j \ge 1,\ a \mid n + j} 2^{-j},$$
so $w(a, 0) = \frac{1}{2^a - 1}$ and the sum in question is $\sum_{a \in A} w(a, 0)$. If it were $p/q$, the numbers $R_n = q \sum_{a \in A} w(a, n)$ would all be positive integers; the Chinese remainder theorem and an averaging choice produce an $N$ with $2^m \mid R_{N+m}$, hence $R_{N+m} \ge 2^m$, while the same choice makes $R_{N+m} < q(m+4) < 2^m$. The work is in private helpers, chiefly `main_contra`.

## The set and the hypothesis

The theorem first shows $0 \notin A$: if $0 \in A$, coprimality of $0$ with any other element $a$ forces $a = 1$, so $A \subseteq \{0, 1\}$ would be finite. Hence every $a \in A$ is at least $1$. Summability of $n \mapsto \frac1n$ on $A$ is restated as summability of its indicator, and the sum over $A$ is identified with $q^{-1} R_0$ for $p/q$ the rational in lowest terms.

## Integrality

`w_step`: $2\,w(a, n) = w(a, n+1) + [a \mid n+1]$. Iterating (`w_shift`): $2^m w(a, n) = w(a, n+m) + D(a, n, m)$ with $D(a, n, m) = \sum_{j=1}^{m} [a \mid n+j]\, 2^{m-j} \in \mathbb{N}$. Summing over $A$ (`R_shift`): $2^m R_n = R_{n+m} + q \sum_{a \in A} D(a, n, m)$, a finite sum since $D(a, n, m) = 0$ for $a > n + m$. From $R_0 = p$ every $R_n$ is an integer (`R_int`), and $R_n > 0$ since every $w(a, n) > 0$ (`R_pos`).

## The construction

`main_contra`. Choose $m \ge 1$ with $q(m+4) < 2^m$ (`exists_m`) and put $\delta = 2^{-m}$. By summability (`tail_small`) take $K$ so that elements of $A$ above $K$ have $\sum 1/a \le \delta/4$, with $K \ge m$. Let $C_0 = A \cap [0, K]$, $c = \sum_{a \in C_0} D(a, 0, m)$, and $r = 2^m - (c \bmod 2^m)$, so that $2^m \mid c + r$. Take a set $B$ of $r$ elements of $A$ above $K$. With $P = \prod_{a \in C_0} a$ and $Q = \prod_{b \in B} b$, coprime because $A$ is pairwise coprime, the Chinese remainder theorem gives $N_0$ with $P \mid N_0$ and $Q \mid N_0 + m$; both persist for $N = N_0 + tL$, $L = PQ$.

## Averaging the uncontrolled elements

Every element of $U = A \setminus (C_0 \cup B)$ exceeds $K$ and is coprime to $L$. For $a$ coprime to $L$, as $t$ runs over $a$ consecutive values the residues of $N_0 + tL$ modulo $a$ run over all residues, so those $a$ values of $w(a, N_0 + tL)$ sum to exactly $1$ (`block_sum`); with the tail bounds of $\sum_{a \in U} 1/a$ this gives some $t < X$ (`exists_good`) with
$$V = \sum_{a \in U} w(a, N) < \delta = 2^{-m}, \qquad N = N_0 + tL.$$

## The contradiction

At this $N$: for $a \in C_0$, $a \mid N$, so $D(a, N, m) = D(a, 0, m)$ (`D_of_dvd`); for $b \in B$, $b > m$ and $b \mid N + m$, so $D(b, N, m) = 1$ (`D_forced`); for $a \in U$, $2^m w(a, N) < 1$ means no $N + j$ with $1 \le j \le m$ is a multiple of $a$, so $D(a, N, m) = 0$. Hence $\sum_{a \in A} D(a, N, m) = c + r$, divisible by $2^m$, so $R_{N+m} = 2^m R_N - q(c+r) = 2^m y$ with $y$ an integer, and $y \ge 1$ since $R_{N+m} > 0$: $R_{N+m} \ge 2^m$. On the other hand $w(a, N+m) \le \min\bigl(1, \frac{2^m}{2^a - 1}\bigr)$ for $a \in C_0 \cup B$, and these sum to at most $m + 3$ (`sum_beta`), while for $a \in U$, $w(a, N+m) = 2^m w(a, N)$, which sum to $2^m V < 1$. So $R_{N+m} < q(m+4) < 2^m$, a contradiction.
