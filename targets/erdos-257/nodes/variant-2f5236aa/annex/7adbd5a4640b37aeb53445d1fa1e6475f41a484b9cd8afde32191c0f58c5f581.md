Erdős (1948) for A = ℕ: the argument the Lean proof submitted on this node follows (proof found by Aristotle, Harmonic, from the outline below; helper names in brackets).

Write d(n) for the number of divisors of n and x = Σ_{n≥1} 1/(2^n − 1).

1. Lambert identity. Expanding 1/(2^a − 1) = Σ_{c≥1} 2^{−ac} and grouping by n = ac gives x = Σ_{n≥1} d(n)/2^n. (Mathlib: tsum_pow_div_one_sub_eq_tsum_sigma with k = 0, r = 1/2.)

2. Tail identity. For every N, 2^N·x = I_N + T(N), where I_N = Σ_{n≤N} d(n)·2^{N−n} is an integer and T(N) = Σ_{j≥1} d(N+j)/2^j > 0.

3. Integrality. If x = a/b with b > 0, then b·T(N) = a·2^N − b·I_N is a positive integer for every N.

4. The 2-adic step. If 2^m divides d(k+j) for every 1 ≤ j ≤ m, then every term d(n)·2^{k+m−n} of I_{k+m} is divisible by 2^m (for n ≤ k because the exponent is at least m, for n = k+j because of the hypothesis), so 2^m divides b·T(k+m), and being positive, b·T(k+m) ≥ 2^m.

5. The number-theoretic core: for every b > 0 there are k, m with 2^m | d(k+j) for 1 ≤ j ≤ m and b·T(k+m) < 2^m. This contradicts step 4, so x is irrational.

Why the core is true (Erdős's argument, as formalized: Bertrand's postulate supplies one prime in each interval (2^e, 2^{e+1}], Mathlib's CRT the residue, [sum_dd_AP_le] the averaging, [tail_upper] the far tail; see J. M. Campbell, arXiv:2605.24160, §2 and Lemma 2). Take m² distinct primes q_{j,i} (1 ≤ j, i ≤ m), all larger than a bound L. By the Chinese remainder theorem choose c with c + j ≡ P_j (mod P_j²), P_j = Π_i q_{j,i}; then each q_{j,i} divides c + tQ + j exactly once for every t, where Q = Π P_j², so 2^m | d(c + tQ + j). The primes exceed L, so c + tQ + m + i is coprime to Q for 1 ≤ i ≤ L − m. Averaging the divisor function over the progression (Σ_{t<X} d(r + tQ) ≤ 2X(1 + ½ log Y) + 2√Y for (r, Q) = 1 and r + tQ ≤ Y, by pairing each divisor with its cofactor) shows some t has T(c + tQ + m) = O(log(QX)) = O(m² log m) for the terms up to L, the rest being negligible by d(n) ≤ n and the factor 2^{−j}. Since b·O(m² log m) < 2^m for m large, k = c + tQ works.
