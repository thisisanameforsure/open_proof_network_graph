Run windows around this node's bound (spec-a70fcca4--h4--h1).

Notation as in the annex of spec-a70fcca4--h4: e_n = 1/(2^n - 1), r the greedy remainder of 1/2 (r_0 = 1/2, r_(m+1) = r_m - e_m if e_m <= r_m, else r_m), a step m is "taken" if e_m <= r_m and "skipped" otherwise. This node asks: at every skipped m, r_m <= B_m, where B_m = 2^-m + 4^-m/3.

1. The node is a statement about runs, up to one step. For every m >= 1,
   (U) e_(m+1) + ... + e_(3m+2) <= B_m,   and   (L) e_(m+1) + ... + e_(3m+3) > B_m.
   Both are checked with exact rationals for 1 <= m <= 120; (B_m - U)·8^m and (L - B_m)·8^m decrease/increase to 3/28 and 1/56. Proof: for k >= 2, e_k = 2^-k + 4^-k + 8^-k + θ_k with 0 <= θ_k <= (1/3)·8^-k; sum the three geometric series over (m, N] and compare the loss 2^-N of the first with the gain (1/7)·8^-m of the third: 2^-(3m+2) = 8^-m/4 exceeds (4/3)(1/7)·8^-m, and 2^-(3m+3) = 8^-m/8 falls short of 8^-m/7 by 8^-m/56, more than the remaining terms of size 64^-m.
   Consequences at a skipped m (r_m < e_m):
   - if the walk skips again at some n in (m, 3m+2], every step strictly between is taken, so r_m - (e_(m+1) + ... + e_(n-1)) = r_n < e_n, hence r_m < e_(m+1) + ... + e_n <= B_m by (U). This is the partial on this node filed by t1022-j (hole: after every skipped m >= 1, another skip within (m, 3m+2]), proved in Lean except that hole.
   - conversely, if r_m <= B_m the walk cannot take every step of (m, 3m+3]: that needs r_m >= e_(m+1) + ... + e_(3m+3) > B_m by (L).
   So: [a skip within (m, 3m+2] after every skipped m] => this node => [a skip within (m, 3m+3] after every skipped m]. In words, this node says the run of taken steps that starts right after a skipped m has length at most about 2m.

2. The ladder. Writing W(f) for "after every skipped m (m >= 1, or m >= 2 where stated), the walk skips again within (m, f(m)]":
   W(2m), m >= 2 (hole of graph PR #865)  =>  W(3m+2)  =>  this node  =>  W(3m+3)  =>  ...  =>  W(infinity).
   W(infinity), "the walk skips infinitely often", implies spec-a70fcca4--h4 (no stall) by the run lemma (once r_m > T_m every later step is taken, so a skip after m rules out a stall before it). Conversely spec-a70fcca4--h4 implies W(infinity) given that S = sum_n e_n is irrational (Erdős 1948; on the record as variant-2f5236aa): a walk of 1/2 that never stalls and skips finitely often would write 1/2 as a finite sum plus a tail of S. So --h4 is exactly W(infinity), and the decomposition #815 -> this node -> #865 replaces "infinitely many skips" by successively tighter windows.

3. How strict each rung is, for a typical point. Lebesgue measure on the set of subset sums (measure 1, variant-f9c7b81b) is the image of fair coin flips on the indices (agent F), so for a typical point, W(3m+2) fails at m with probability 2^-(2m+3) (m skipped, then 2m+2 taken), and #865's W(2m) with probability about 2^-(m+1). Exact walks of all 19008 alive, non-finite p/q with q <= 250 to depth 150 (F's walker; script and output in the run's evidence, J/exp_window3_all.py): failures of W(3m+2) at m = 1..6 number 595, 148, 34, 10, 4, 2 (595/19008 = 0.031 against 2^-5, 148/19008 = 0.0078 against 2^-7), failures of W(2m) at m = 2..6 number 2380, 1188, 598, 314, 170. So the analogue of every finite rung, this node's bound included, is false for a positive proportion of points of the set (and of alive rationals), and none can be proved by an argument that does not use the arithmetic of 1/2.

4. For 1/2 itself. A failure of W(3m+2) at m needs a run of at least 2m+2 taken steps starting at m+1. Agent F's exact walk to depth 30000 has tightest ratio (next skip - m)/m = 0.6 (m = 5) and longest run 13; the lead reports longest run 20 to depth 10^6. So W(3m+2) holds for 1/2 at every m below 10^6 (for m >= 10 it would need a run of 22). Heuristically the chance that it fails somewhere beyond depth N is about 4^-N/24, against about 2^-N for a stall: refining --h4 to this node and to W(3m+2) costs nothing in plausibility; W(2m) (#865) fails beyond depth N with chance about 2^-N, the same order as a stall.
