$$\Bigl(\forall\, A \subseteq \mathbb{N}\ \text{infinite}:\ \sum_{n\in A}\frac{1}{2^n-1}\notin\mathbb{Q}\Bigr) \;\Longrightarrow\; \Bigl(\forall\, A \subseteq \mathbb{N}\ \text{infinite},\ 0\notin A,\ \ \bigl(\forall C\ \exists m\in A:\ C+\sum_{a\in A,\ a<m} a\ \le\ m\bigr):\ \ \sum_{n\in A}\frac{1}{2^n-1}\notin\mathbb{Q}\Bigr).$$

The hypothesis is the root statement; the conclusion is this node's statement, with $C$ a natural number. In Lean the inner sum runs over a finite set $F$ required to have exactly the elements of $A$ below $m$. So the file proves that the root implies this node.

The Lean takes a set $A$ meeting the node's hypotheses, discards the two extra ones ($0\notin A$ and the gap condition), and applies the root to $A$, using only that $A$ is infinite. The node is the root restricted to fewer sets.
