## What the assembly shows, and where it stands

The node says that $\sum_{n\in B}\frac{1}{2^n-1}$ is irrational for every nonempty $B\subseteq\mathbb{N}$ with $n\in B\iff n+P\in B$ for some $P\ge1$. This is the second partial on the node. It makes the same reduction as the first (Erdős's 1948 argument with $f_B(n)$, the number of divisors of $n$ in $B$, in place of the divisor function $d$) to a weaker hole: the primes need only exceed $2m^2+m$ and have a bounded product, instead of lying in $(2^m,2^{m+m^2}]$, and the averaging step is changed to pay for that.

This route cannot be completed as stated. The hole (node `variant-5274cf38--h1--h2`) is false at $P=1$: in Lean `p % 1` is $0$, so no prime meets the hole's condition `p % P = 1`, while the hole asks for $m^2\ge1$ of them (defect claim, graph pull request #1326, 12 November 2026). The intended hypothesis is $2\le P$. The assembly applies the hole once, at the period $P$ it is handed, so it meets the false instance exactly when that period is $1$, that is, when $B=\mathbb{N}$. The node itself was proved on 12 November 2026 by a direct proof (graph pull request #1385) that uses neither partial. A comment above the hole sketches a proof by cyclotomic polynomials; no such proof is in the file. Everything below except the hole is proved in the file.

## The hole: primes with a bounded product

For every $P\ge1$ and $m\ge1$ there is a set $S$ of $m^2$ primes, each with `p % P = 1` and $p>2m^2+m$, such that $\prod_{p\in S}p\le 2^{1000P^3m^{12}}$.

## What is taken over from the first partial

The lemmas are the same text as in the first partial: the Lambert identity $\sum_{n\in B}\frac{1}{2^n-1}=\sum_{m\ge0}f_B(m)/2^m$; if the sum is $a/b$ with $b\ge1$, the tails $T_j=b\sum_{i\ge1}f_B(j+i)/2^i$ are positive integers, divisible by $2^m$ at $j=k+m$ when $2^m\mid f_B(n)$ for $k<n\le k+m$; and if $n\ne0$ and each prime $p$ of a set $S$ has `p % P = 1`, $p\mid n$, $p^2\nmid n$, then $2^{|S|}\mid f_B(n)$.

Choose $m\ge\max(b,1)$ with $4m(3+q)+1<2^m$, where $q=2000P^3m^{12}$. Index the hole's primes for $P$ and $m$ as $p_{i,j}$, $i,j<m$, and let $Q=\prod p_{i,j}^2$; by the product bound $Q\le2^q$. The Chinese remainder theorem gives $c<Q$ with $c+(i+1)\equiv p_{i,j}\pmod{p_{i,j}^2}$. For every $t$ and $i<m$, $c+tQ+(i+1)$ is then divisible exactly once by each of $p_{i,0},\dots,p_{i,m-1}$, so $2^m\mid f_B$ there, and $T_{c+tQ+m}\ge 2^m$ for every $t$.

## The weighted average

Put $p_0=2m^2+m+1$, so every $p_{i,j}\ge p_0$. For $i<3q$ with $m+i<p_0$ the number $c+m+i+1$ is coprime to $Q$: a prime $p_{i',j}$ dividing it would divide $m+i-i'$, which is positive and less than $p_0$. For the other $i$, $g=\gcd(c+m+i+1,Q)$ divides $Q$, so $d(g)\le d(Q)=3^{m^2}\le2^{2m^2}\le2^{p_0-m}$.

For any start $r$, with $g=\gcd(r,Q)$, factoring $g$ out and using $d(gn)\le d(g)d(n)$ and the coprime bound of the first partial, $\sum_{t<X}d(r+tQ)\le d(g)\,2X(2+\log X)$. Put $X=Q+m+3q$. As in the first partial, for $t<X$, $T_{c+tQ+m}\le b\sum_{i<3q}d(c+m+i+1+tQ)/2^{i+1}+1$. Summing over $t<X$, position $i$ contributes at most $w_i2^{-(i+1)}\,b\,2X(2+\log X)$, with $w_i=1$ if $m+i<p_0$ and $w_i=d(Q)$ otherwise. Since $d(Q)2^{-(i+1)}\le2^{-(i+1-(p_0-m))}$ for $i\ge p_0-m$, the weights satisfy $\sum_{i<3q}w_i2^{-(i+1)}\le1+1=2$. Hence $X2^m\le4bX(2+\log X)+X$, and, as $X\le2^{q+1}$ and $b\le m$, $2^m\le4b(3+q)+1<2^m$. This contradiction shows the sum is irrational.
