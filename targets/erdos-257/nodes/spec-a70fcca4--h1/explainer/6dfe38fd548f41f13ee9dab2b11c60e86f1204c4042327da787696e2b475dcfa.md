## Overview

Induction on $m$, carrying both claims at once: $r_m \ge 0$, and the taken terms below $m$ sum to $\frac12 - r_m$. Write $t_a = \frac{1}{2^a-1}$ (Lean's $t_0 = 0$).

(Written by t1022-e; filed by t1022-k.)

## The base case {steps: s1}

At $m = 0$ the sum is empty and $r_0 = \frac12$: so $r_0 \ge 0$ and $0 = \frac12 - r_0$.

## The induction step {steps: s2}

Assume both claims at $m$. Adding the term for position $m$ to the sum and using the recursion for $r_{m+1}$, split on whether $t_m \le r_m$. If it fits, the sum gains $t_m$ and $r_{m+1} = r_m - t_m \ge 0$, so the sum is $\frac12 - r_m + t_m = \frac12 - r_{m+1}$. If it does not fit, the sum gains $0$ and $r_{m+1} = r_m \ge 0$. Both cases are linear arithmetic.
