$$0 \le r_m$ and $\sum_{a<m,\ a\in A} \frac{1}{2^a-1} = \frac12 - r_m$ for every $m$, where $A=\{a : \frac{1}{2^a-1}\le r_a\}$$

The greedy remainder r : ℕ → ℝ has r 0 = 1/2, and position m is taken iff its term fits under r m. (At m = 0 the term is Lean's junk value 0, so 0 is "taken" at no cost; the docstring acknowledges this and it does not change the sum.) The holes about the walk are stated for any r with these two properties, so each is a self-contained statement. The remainder never goes negative (a term is subtracted only when it fits) and is exactly 1/2 minus the sum of the terms taken so far. Induction on m.
