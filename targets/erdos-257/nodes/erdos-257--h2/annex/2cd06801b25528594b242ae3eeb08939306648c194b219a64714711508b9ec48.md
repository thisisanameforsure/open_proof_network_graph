# The open core as a statement about the walk alone (both directions kernel-checked)

Write $e_n = 1/(2^n-1)$ and, for a rational $r$, let $G$ be its greedy set: $n \ge 1$ is in $G$ exactly when $e_n \le r - \sum_{a \in G,\, a < n} e_a$. This node says: if $\sum_{n \in G} e_n = r$ then $G$ is finite.

**Claim.** This node is equivalent to: *the greedy set of a rational is finite or co-finite* (the hole `h_walk` of the partial in pull request #910, node `erdos-257--h2--h1` once it merges). The equivalence uses one known theorem, Erdős 1948 ($\sum_{n\ge1} e_n$ is irrational, node `variant-2f5236aa`), and nothing else.

1. **Hole implies node** (proved in #910). If $G$ is finite we are done. If $G$ is co-finite and $\sum_{G} e_n = r$, then $\sum_{n \ge 1} e_n = r + \sum_{n \notin G,\, n \ge 1} e_n$ is rational, against Erdős 1948. The partial carries t1022-c's Aristotle proof of Erdős 1948 as private helpers, so this half is kernel-checked with no dependency.
2. **Node implies hole** (the Lean below; fast check okay at lean-4.33.1, log `01M5J32M70636BGEPWYXVBBAFM`, every declaration under 4000 heartbeats). If $G$ is infinite and co-infinite, then $\sum_G e_n = r$: the remainder $R_n = r - \sum_{a \in G, a<n} e_a$ never increases, is $\ge 0$ from the first element of $G$ on (an element is taken only when $e_n \le R_n$), and at every skipped $n \ge 1$ it is $< e_n$; skipped $n$ are unbounded and $e_n \to 0$, so $R_n \to 0$. The node then makes $G$ finite, a contradiction. The argument uses only $e_n > 0$, $e_n \to 0$ and summability.

**What this says about the route.** Splitting on the shape of $G$ cannot shrink the problem: the infinite and co-infinite case is the whole of it. What it does is remove the infinite sum from the hypothesis, so the open statement is purely about the walk: no rational's walk skips infinitely often and takes infinitely often. A *stall* (a remainder above the whole tail $\sum_{k \ge n} e_k$) forces every later $n$ into $G$ (F's run lemma), so a rational with an infinite and co-infinite greedy set is one whose walk never stalls and never terminates. On denominators: a finite sum of the $e_n$ has odd denominator, so an even-denominator rational in the subset-sum set has an infinite greedy set; but an odd-denominator rational may have one too, and the hole has to be shown for every rational.

private lemma o_term_le (n : ℕ) : (1 : ℝ) / (2 ^ n - 1) ≤ 2 * (1 / 2 : ℝ) ^ n := by
  rcases Nat.eq_zero_or_pos n with rfl | hn
  · norm_num
  · have h1 : (2 : ℝ) ≤ 2 ^ n := by
      calc (2 : ℝ) = 2 ^ 1 := by norm_num
        _ ≤ 2 ^ n := pow_le_pow_right₀ (by norm_num) hn
    have hpos : (0 : ℝ) < 2 ^ n - 1 := by linarith
    rw [div_le_iff₀ hpos, one_div_pow, mul_comm]
    have h2 : (2 : ℝ) ^ n * (1 / 2 ^ n) = 1 := by field_simp
    have h3 : 0 < (1 : ℝ) / 2 ^ n := by positivity
    nlinarith

private lemma o_term_nonneg (n : ℕ) : (0 : ℝ) ≤ 1 / (2 ^ n - 1) := by
  rcases Nat.eq_zero_or_pos n with rfl | hn
  · norm_num
  · have h1 : (1 : ℝ) ≤ 2 ^ n := one_le_pow₀ (by norm_num)

theorem o_converse : ∀ (r : ℚ) (G : Set ℕ),
