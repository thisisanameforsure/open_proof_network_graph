$$\Bigl(\exists\, A \subseteq \mathbb{N}\ \text{infinite},\ \exists\, s\in\mathbb{Q}:\ \sum_{n\in A}\frac{1}{2^n-1}=s\Bigr) \;\Longrightarrow\; \neg\,\Bigl(\forall\, A \subseteq \mathbb{N}\ \text{infinite}:\ \sum_{n\in A}\frac{1}{2^n-1}\notin\mathbb{Q}\Bigr).$$

The hypothesis is this node's statement; the negated statement is the root. So the file proves that this node implies the negation of the root: a proof of the node would refute the root.

The Lean takes the set $A$ and the rational $s$ the node provides, assumes the root, and applies it to $A$. That says the sum over $A$ is irrational, which in Lean means it equals no rational number; it equals $s$, a contradiction.
