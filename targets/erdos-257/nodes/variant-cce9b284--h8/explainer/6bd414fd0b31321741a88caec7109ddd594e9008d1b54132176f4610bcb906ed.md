## Statement

For a finite set $A$ of positive integers, $\sum_{a \in A} \frac{1}{2^a - 1} \ne 2^{-20}$. The `tsum` over the finite set is first rewritten as a `Finset` sum over `A.toFinset`.

## Clearing denominators

Put $D = \prod_{a \in A} (2^a - 1)$. Each $2^a - 1$ with $a \ge 1$ is odd, so $D$ is odd. Each $2^a - 1$ divides $D$, so $D \sum_{a \in A} \frac{1}{2^a - 1} = N$ with $N = \sum_{a\in A} D/(2^a-1)$ a natural number. The natural-number $2^a - 1$ (truncated subtraction) is exact since $2^a \ge 1$, which `opn_cast_mersenne` records.

## Parity

If the sum were $2^{-20}$, then $D = 2^{20} N$, which is even. That contradicts $D$ odd. $\blacksquare$

This is the case $j = 20$ of `variant-cce9b284--h13`, proved by the same argument.
